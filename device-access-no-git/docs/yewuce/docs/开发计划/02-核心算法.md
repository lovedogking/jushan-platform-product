# 2. 核心算法伪代码

> 来源：/docs/需求文档/停车SaaS系统完整需求文档_PRD_V1.0_最终定稿.md
> 适用范围：收费规则、一位多车、优惠券、车位余量、车辆进出策略

---

## 2.0 共享规范（所有算法必须遵守）

1. **多租户隔离**：所有业务表必须包含 `tenant_id BIGINT NOT NULL`，所有 SQL 查询必须带 `tenant_id = ?` 过滤。
2. **软删除**：所有业务表必须包含 `deleted_at DATETIME DEFAULT NULL`；删除时更新为当前时间，查询时过滤 `deleted_at IS NULL`。
3. **金额字段**：统一使用 `DECIMAL(18,2)`（元）或 `DECIMAL(18,4)`（积分/费率），禁止 `FLOAT/DOUBLE`。
4. **车牌存储**：车牌号码统一转大写持久化；查询时业务层先转大写再匹配。
5. **操作日志**：配置变更类操作必须记录 `operator_id`、`operator_ip`、`operation_time`、变更前后值 `before_value/after_value` JSON。
6. **并发控制**：车位余量、优惠券库存、积分扣减必须使用 **Redis 分布式锁 + 数据库乐观锁（version 字段）**。
7. **时间字段**：使用 `DATETIME(3)` 或 `DATETIME`。
8. **预留接口**：未实现能力标注【预留】，返回 mock 或空实现，但字段定义必须完整。

## 2.1 收费规则计算引擎

### 业务说明
支持按 `parking_lot`（车场）和 `parking_zone`（区域）两级配置；区域未配置时继承车场规则。计费模式包括按时、按次、阶梯、分时段；支持免费时长、24 小时封顶、夜间封顶、节假日特殊规则、优惠券抵扣、积分抵扣。

### 输入

| 参数 | 类型 | 说明 |
|------|------|------|
| tenantId | Long | 租户 ID |
| lotId | Long | 停车场 ID |
| zoneId | Long | 区域 ID（可选） |
| plateNumber | String | 车牌号（已转大写） |
| entryTime | LocalDateTime | 入场时间 |
| exitTime | LocalDateTime | 出场时间 |
| vehicleType | String | 车辆类型：TEMP/MONTH/WALLET/FREE/VIP |
| couponList | List<UserCoupon> | 用户可用优惠券实例 |
| pointsToUse | Integer | 拟使用积分数量 |

### 输出

| 字段 | 类型 | 说明 |
|------|------|------|
| originalAmount | BigDecimal | 原始应收金额 |
| freeAmount | BigDecimal | 免费时长抵扣金额 |
| couponAmount | BigDecimal | 优惠券抵扣金额 |
| pointsAmount | BigDecimal | 积分抵扣金额 |
| payableAmount | BigDecimal | 最终应付金额（≥ 0） |
| feeRuleId | Long | 命中的收费规则 ID |
| feeDetail | JSON | 费用明细（时段拆分） |

### 边界条件

- 出场时间早于入场时间：抛 `BizException`。
- 免费车时：直接返回 0。
- 停车时长 ≤ 免费时长：返回 0。
- 优惠券抵扣不得超过 `originalAmount`。
- 积分抵扣有单日/单笔上限，且折算金额不得超过剩余应付金额。
- 最终 `payableAmount = max(0, originalAmount - freeAmount - couponAmount - pointsAmount)`。

### 异常处理

- 未找到可用收费规则：返回 `BizException(ERR_FEE_RULE_NOT_FOUND)`。
- 节假日规则冲突：按优先级 `区域特殊规则 > 车场通用规则 > 平台默认规则` 选择。
- 金额计算全程使用 `BigDecimal`，禁止浮点运算。

### 伪代码

```java
public FeeCalcResult calculateParkingFee(FeeCalcRequest req) {
    // 1. 基础校验
    if (req.exitTime.isBefore(req.entryTime)) {
        throw new BizException("出场时间不能早于入场时间");
    }
    if (req.vehicleType.equals("FREE") || req.vehicleType.equals("VIP")) {
        return FeeCalcResult.zero();
    }

    // 2. 选择收费规则（区域 > 车场 > 平台默认）
    FeeRule rule = selectFeeRule(req.tenantId, req.lotId, req.zoneId, req.entryTime);
    if (rule == null) {
        throw new BizException(ERR_FEE_RULE_NOT_FOUND);
    }

    // 3. 判断节假日/临时特殊规则
    FeeRule effectiveRule = applyHolidayOverride(rule, req.entryTime, req.exitTime);

    // 4. 计算原始应收金额
    BigDecimal originalAmount = computeOriginalFee(effectiveRule, req.entryTime, req.exitTime);

    // 5. 免费时长抵扣
    BigDecimal freeAmount = computeFreeMinutesDeduction(effectiveRule, req.entryTime, req.exitTime, originalAmount);
    BigDecimal afterFree = originalAmount.subtract(freeAmount).max(BigDecimal.ZERO);

    // 6. 优惠券最优匹配
    CouponMatchResult couponResult = couponMatchService.findBestCoupons(
        req.tenantId, req.lotId, req.plateNumber, afterFree, req.couponList
    );
    BigDecimal afterCoupon = afterFree.subtract(couponResult.getTotalDeduction()).max(BigDecimal.ZERO);

    // 7. 积分抵扣
    PointsDeductionResult pointsResult = pointsService.calcDeduction(
        req.tenantId, req.plateNumber, req.pointsToUse, afterCoupon
    );
    BigDecimal payable = afterCoupon.subtract(pointsResult.getAmount()).max(BigDecimal.ZERO);

    // 8. 组装结果
    return FeeCalcResult.builder()
        .originalAmount(originalAmount)
        .freeAmount(freeAmount)
        .couponAmount(couponResult.getTotalDeduction())
        .pointsAmount(pointsResult.getAmount())
        .payableAmount(payable)
        .feeRuleId(effectiveRule.getId())
        .feeDetail(buildFeeDetail(effectiveRule, req.entryTime, req.exitTime))
        .build();
}

private FeeRule selectFeeRule(Long tenantId, Long lotId, Long zoneId, LocalDateTime time) {
    // 区域特殊规则（当前时段启用）
    if (zoneId != null) {
        FeeRule zoneRule = feeRuleMapper.selectActiveByZone(tenantId, lotId, zoneId, time);
        if (zoneRule != null) return zoneRule;
    }
    // 车场通用规则
    FeeRule lotRule = feeRuleMapper.selectActiveByLot(tenantId, lotId, time);
    if (lotRule != null) return lotRule;
    // 平台默认规则
    return feeRuleMapper.selectDefaultRule(tenantId);
}

private BigDecimal computeOriginalFee(FeeRule rule, LocalDateTime entry, LocalDateTime exit) {
    long totalMinutes = ChronoUnit.MINUTES.between(entry, exit);
    if (totalMinutes <= rule.getFreeMinutes()) {
        return BigDecimal.ZERO;
    }

    switch (rule.getBillingMode()) {
        case "PER_TIME":
            return rule.getPerTimePrice();
        case "BY_HOUR":
            return calcByHour(rule, entry, exit, totalMinutes);
        case "TIERED":
            return calcTiered(rule, entry, exit, totalMinutes);
        case "TIME_SEGMENT":
            return calcTimeSegment(rule, entry, exit);
        default:
            throw new BizException("不支持的计费模式: " + rule.getBillingMode());
    }
}

private BigDecimal calcTimeSegment(FeeRule rule, LocalDateTime entry, LocalDateTime exit) {
    BigDecimal total = BigDecimal.ZERO;
    LocalDateTime cursor = entry;
    while (cursor.isBefore(exit)) {
        FeeRuleSegment segment = findSegment(rule, cursor);
        LocalDateTime segmentEnd = min(segment.getEndOfCurrentSegment(cursor), exit);
        long minutes = ChronoUnit.MINUTES.between(cursor, segmentEnd);

        // 首时段价格（仅每自然日首次进入该时段时生效）
        BigDecimal segmentFee = calcSegmentFee(segment, minutes, cursor.toLocalDate());
        total = total.add(segmentFee);
        cursor = segmentEnd;
    }
    return total;
}
```

## 2.2 一位多车判断逻辑

### 业务说明
一个车位（或月卡）可绑定多个车牌，但同时仅有一辆车享受固定车/VIP 待遇。第二辆车按车场策略处理；第一辆固定车出场后，第二辆可自动升级。

### 输入

| 参数 | 类型 | 说明 |
|------|------|------|
| tenantId | Long | 租户 ID |
| lotId | Long | 车场 ID |
| plateNumber | String | 当前识别车牌 |
| accessType | String | ENTRY / EXIT |
| eventTime | LocalDateTime | 识别时间 |

### 输出

| 字段 | 类型 | 说明 |
|------|------|------|
| effectivePlate | String | 实际生效的车牌（可能为原车牌） |
| vehicleType | String | 实际按何种类型处理：MONTH/TEMP/VIP 等 |
| policyAction | String | 命中的一位多车策略动作 |
| upgradeFromPlate | String | 自动升级场景：被替换出场的车牌 |

### 边界条件

- 未启用一位多车：直接按 `vehicle` 表类型返回。
- 绑定数量超过 `max_bind_count`：拒绝新增绑定（伪代码聚焦判断，新增绑定另做校验）。
- 主车在场，第二辆车入场：按车场策略处理（默认变 `TEMP`）。
- 主车出场，副车仍在场：按策略自动升级副车为 `MONTH`。
- 多辆车同时入场：仅第一辆享受固定车待遇，其余按策略处理。

### 异常处理

- 查不到车位绑定关系：按普通临时车处理。
- 数据不一致（多主车同时在场）：记录告警并降级为临时车处理。

### 伪代码

```java
public MultiPlateResult evaluateMultiPlate(MultiPlateRequest req) {
    // 1. 查询车辆登记信息
    Vehicle vehicle = vehicleMapper.selectByPlateAndLot(
        req.tenantId, req.lotId, req.plateNumber.toUpperCase()
    );
    if (vehicle == null) {
        return MultiPlateResult.temp(req.plateNumber);
    }

    // 2. 是否启用一位多车
    ParkingLotConfig config = lotConfigService.getConfig(req.tenantId, req.lotId);
    if (!config.getMultiPlateEnabled()) {
        return MultiPlateResult.of(vehicle);
    }

    // 3. 查询一位多车绑定关系
    VehicleMultiPlate binding = vehicleMultiPlateMapper.selectByPlate(
        req.tenantId, req.lotId, req.plateNumber.toUpperCase()
    );
    if (binding == null) {
        return MultiPlateResult.of(vehicle);
    }

    // 4. 获取同车位下所有绑定车牌
    List<String> boundPlates = vehicleMultiPlateMapper.selectPlatesByParkingSpace(
        req.tenantId, req.lotId, binding.getParkingSpaceId()
    );

    // 5. 查询在场车辆（按车位聚合）
    List<ParkingSession> inLotSessions = parkingSessionMapper.selectInLotByPlates(
        req.tenantId, req.lotId, boundPlates
    );

    if (req.accessType.equals("ENTRY")) {
        return handleEntry(req, vehicle, binding, inLotSessions, config);
    } else {
        return handleExit(req, vehicle, binding, inLotSessions, config);
    }
}

private MultiPlateResult handleEntry(MultiPlateRequest req, Vehicle vehicle,
                                     VehicleMultiPlate binding,
                                     List<ParkingSession> inLotSessions,
                                     ParkingLotConfig config) {
    // 已有同车位车辆在场
    boolean alreadyHasPriority = inLotSessions.stream()
        .anyMatch(s -> s.getPlateNumber().equals(req.plateNumber)
            && s.getPriority() == 1);

    if (alreadyHasPriority) {
        // 主车重复入场：按车场重复入场策略处理（此处返回覆盖）
        return MultiPlateResult.of(vehicle).withAction("OVERWRITE_ENTRY");
    }

    long inLotCount = inLotSessions.size();
    if (inLotCount == 0) {
        // 第一辆入场，正常享受固定车待遇
        return MultiPlateResult.of(vehicle).withAction("NORMAL").withPriority(1);
    }

    // 已有车辆在场，当前为第二辆
    String action = config.getSecondCarEntryPolicy(); // TEMP/REJECT/CONFIRM/NO_GATE/REDUCE
    switch (action) {
        case "TEMP":
            return MultiPlateResult.temp(req.plateNumber)
                .withAction("SECOND_CAR_AS_TEMP");
        case "REJECT":
            return MultiPlateResult.reject(req.plateNumber)
                .withAction("SECOND_CAR_REJECT");
        case "CONFIRM":
            return MultiPlateResult.confirm(req.plateNumber)
                .withAction("SECOND_CAR_CONFIRM");
        case "NO_GATE":
            return MultiPlateResult.noGate(req.plateNumber)
                .withAction("SECOND_CAR_NO_GATE");
        case "REDUCE":
            return MultiPlateResult.reduce(req.plateNumber)
                .withAction("SECOND_CAR_REDUCED");
        default:
            return MultiPlateResult.temp(req.plateNumber);
    }
}

private MultiPlateResult handleExit(MultiPlateRequest req, Vehicle vehicle,
                                    VehicleMultiPlate binding,
                                    List<ParkingSession> inLotSessions,
                                    ParkingLotConfig config) {
    ParkingSession leaving = inLotSessions.stream()
        .filter(s -> s.getPlateNumber().equals(req.plateNumber))
        .findFirst()
        .orElse(null);

    if (leaving == null) {
        // 无入场记录出场：转无记录出场策略
        return MultiPlateResult.noEntryRecord(req.plateNumber);
    }

    // 出场后是否自动升级剩余在场车辆
    if (config.getAutoUpgradeAfterExit() && leaving.getPriority() == 1) {
        ParkingSession remaining = inLotSessions.stream()
            .filter(s -> !s.getPlateNumber().equals(req.plateNumber))
            .findFirst()
            .orElse(null);
        if (remaining != null) {
            // 将剩余车辆升级为主车待遇
            upgradeToPriority(remaining);
            return MultiPlateResult.of(vehicle)
                .withAction("EXIT_AND_UPGRADE")
                .withUpgradeFromPlate(req.plateNumber);
        }
    }

    return MultiPlateResult.of(vehicle).withAction("NORMAL_EXIT");
}

private void upgradeToPriority(ParkingSession session) {
    // 更新在场记录优先级 + 写操作日志
    int rows = parkingSessionMapper.updatePriority(
        session.getId(), 1, session.getVersion()
    );
    if (rows == 0) {
        throw new ConcurrentModificationException("一位多车升级冲突");
    }
}
```

## 2.3 优惠券最优匹配算法

### 业务说明
出场结算时，根据用户持有的优惠券实例、适用车场、适用时段、使用门槛、叠加规则，计算最优抵扣组合。

### 输入

| 参数 | 类型 | 说明 |
|------|------|------|
| tenantId | Long | 租户 ID |
| lotId | Long | 车场 ID |
| plateNumber | String | 车牌 |
| originalAmount | BigDecimal | 原始应收金额 |
| couponList | List<UserCoupon> | 用户可用券实例 |

### 输出

| 字段 | 类型 | 说明 |
|------|------|------|
| selectedCoupons | List<UserCoupon> | 选中的券实例 |
| totalDeduction | BigDecimal | 总抵扣金额 |
| finalAmount | BigDecimal | 抵扣后金额 |

### 边界条件

- `originalAmount <= 0`：返回空列表，抵扣 0。
- 商家优惠与平台优惠券默认互斥；若配置可叠加，则先商家优惠后平台券。
- 同一类券每人限领，超过持有数量不可用。
- 券已过有效期、未到可用时段、不满足最低消费：过滤掉。

### 异常处理

- 券库存不足：跳过该券，记录不可使用原因。
- 并发扣减库存失败：重试或抛异常，由上层决定。

### 伪代码

```java
public CouponMatchResult findBestCoupons(CouponMatchRequest req) {
    if (req.originalAmount.compareTo(BigDecimal.ZERO) <= 0) {
        return CouponMatchResult.empty();
    }

    // 1. 过滤无效券
    List<UserCoupon> validCoupons = req.couponList.stream()
        .filter(c -> c.getTenantId().equals(req.tenantId))
        .filter(c -> c.getDeletedAt() == null)
        .filter(c -> c.getStatus().equals("UNUSED"))
        .filter(c -> c.getValidStart().isBefore(now()) && c.getValidEnd().isAfter(now()))
        .filter(c -> isApplicableLot(c, req.lotId))
        .filter(c -> isApplicableTimeWindow(c, now()))
        .filter(c -> req.originalAmount.compareTo(c.getMinConsume()) >= 0)
        .collect(Collectors.toList());

    // 2. 按类型分组
    Map<String, List<UserCoupon>> byType = validCoupons.stream()
        .collect(Collectors.groupingBy(UserCoupon::getCouponType));

    // 3. 商家优惠单独计算
    List<UserCoupon> merchantCoupons = byType.getOrDefault("MERCHANT", Collections.emptyList());
    BigDecimal merchantDeduction = calcMerchantDeduction(merchantCoupons, req.originalAmount);

    // 4. 平台券计算（扣除商家优惠后）
    BigDecimal remainingAfterMerchant = req.originalAmount.subtract(merchantDeduction);
    List<UserCoupon> platformCoupons = byType.entrySet().stream()
        .filter(e -> !e.getKey().equals("MERCHANT"))
        .flatMap(e -> e.getValue().stream())
        .collect(Collectors.toList());

    boolean canStack = pointsConfigService.canStackMerchantAndPlatform(req.tenantId);
    List<UserCoupon> selectedPlatform = Collections.emptyList();
    BigDecimal platformDeduction = BigDecimal.ZERO;

    if (canStack || merchantDeduction.compareTo(BigDecimal.ZERO) == 0) {
        selectedPlatform = selectBestPlatformCoupons(platformCoupons, remainingAfterMerchant);
        platformDeduction = selectedPlatform.stream()
            .map(c -> calcCouponDeduction(c, remainingAfterMerchant))
            .reduce(BigDecimal.ZERO, BigDecimal::add);
    }

    // 5. 汇总
    BigDecimal totalDeduction = merchantDeduction.add(platformDeduction)
        .min(req.originalAmount);
    BigDecimal finalAmount = req.originalAmount.subtract(totalDeduction);

    return CouponMatchResult.builder()
        .selectedCoupons(concat(merchantCoupons, selectedPlatform))
        .totalDeduction(totalDeduction)
        .finalAmount(finalAmount)
        .build();
}

private List<UserCoupon> selectBestPlatformCoupons(List<UserCoupon> coupons, BigDecimal amount) {
    // 贪心策略：按单张抵扣金额倒序，优先使用抵扣金额大的券
    // 复杂场景可用背包动态规划，但通常券数量 <= 20，贪心可接受
    return coupons.stream()
        .sorted(Comparator.comparing(c -> calcCouponDeduction(c, amount), Comparator.reverseOrder()))
        .filter(c -> {
            BigDecimal d = calcCouponDeduction(c, amount);
            return d.compareTo(BigDecimal.ZERO) > 0;
        })
        .collect(Collectors.toList());
}

private BigDecimal calcCouponDeduction(UserCoupon coupon, BigDecimal amount) {
    switch (coupon.getCouponType()) {
        case "AMOUNT":
            return coupon.getValue().min(amount);
        case "DISCOUNT":
            return amount.multiply(BigDecimal.ONE.subtract(coupon.getValue()))
                .setScale(2, RoundingMode.HALF_UP);
        case "FREE_TIME":
            // 时长券需结合计费规则计算，此处返回按规则折算金额
            return timeCouponService.calcDeduction(coupon, amount);
        case "FULL_FREE":
            return amount;
        case "MERCHANT":
            return calcMerchantDeduction(Collections.singletonList(coupon), amount);
        default:
            return BigDecimal.ZERO;
    }
}
```

## 2.4 车位余量实时计算

### 业务说明
支持精准余位和冗余余位两种模式；冗余模式在总车位基础上扣减缓冲数。支持分时段管控（某时段强制视为车位满，白名单车辆除外）。

### 输入

| 参数 | 类型 | 说明 |
|------|------|------|
| tenantId | Long | 租户 ID |
| lotId | Long | 车场 ID |
| zoneId | Long | 区域 ID（可选） |
| vehicleType | String | 当前车辆类型 |
| eventTime | LocalDateTime | 当前时间 |

### 输出

| 字段 | 类型 | 说明 |
|------|------|------|
| totalSpaces | Integer | 总车位数 |
| occupiedSpaces | Integer | 已占用车位数 |
| availableSpaces | Integer | 可用余位数 |
| isFull | Boolean | 是否已满 |
| reason | String | 满位原因：NORMAL/FORCE_FULL_BY_TIME/REDUNDANT |

### 边界条件

- 车辆类型为 VIP 且开启“不受车位满限制”：直接返回 `isFull=false`。
- 白名单车辆（月卡、VIP、内部车）在分时段管控中可不受强制满位限制。
- 冗余模式下 `availableSpaces = total - occupied - buffer`，最小为 0。
- 区域级计算时，仅统计该区域的在场车辆；车场级时聚合所有区域。

### 异常处理

- Redis 分布式锁获取失败：返回“计算中，请重试”或降级为数据库查询。
- 并发冲突：通过数据库 `version` 字段乐观锁重试。

```java
public SpaceAvailabilityResult calcAvailableSpaces(SpaceCalcRequest req) {
    String lockKey = String.format("space:%d:%d:%d", req.tenantId, req.lotId, req.zoneId);
    RLock lock = redissonClient.getLock(lockKey);
    boolean locked = false;
    try {
        locked = lock.tryLock(3, 10, TimeUnit.SECONDS);
        if (!locked) {
            throw new BizException("车位余量计算繁忙，请重试");
        }

        // 1. 读取车场/区域配置
        ParkingSpaceConfig config = spaceConfigService.getConfig(
            req.tenantId, req.lotId, req.zoneId
        );

        // 2. 分时段管控检查
        TimeSegmentControl timeControl = timeSegmentControlService.findActiveControl(
            req.tenantId, req.lotId, req.eventTime
        );
        if (timeControl != null && timeControl.getForceFull()
            && !isWhitelistType(req.vehicleType, timeControl)) {
            return SpaceAvailabilityResult.full()
                .withReason("FORCE_FULL_BY_TIME")
                .withAvailableSpaces(0);
        }

        // 3. 统计在场车辆数
        int occupied = parkingSessionMapper.countInLot(
            req.tenantId, req.lotId, req.zoneId, config.getCountableVehicleTypes()
        );

        // 4. 计算余位
        int total = config.getTotalSpaces();
        int buffer = "REDUNDANT".equals(config.getSpaceMode()) ? config.getBufferSpaces() : 0;
        int available = Math.max(0, total - occupied - buffer);

        return SpaceAvailabilityResult.builder()
            .totalSpaces(total)
            .occupiedSpaces(occupied)
            .availableSpaces(available)
            .isFull(available <= 0)
            .reason("REDUNDANT".equals(config.getSpaceMode()) ? "REDUNDANT" : "NORMAL")
            .build();
    } catch (InterruptedException e) {
        Thread.currentThread().interrupt();
        throw new BizException("车位余量计算被中断");
    } finally {
        if (locked) {
            lock.unlock();
        }
    }
}

public boolean allowEntryWhenFull(SpaceCalcRequest req) {
    // VIP 车、开启不受车位满限制的车辆直接放行
    if ("VIP".equals(req.vehicleType)) {
        VehicleTypeConfig vtc = vehicleTypeConfigMapper.selectByType(
            req.tenantId, req.lotId, "VIP"
        );
        if (vtc != null && Boolean.TRUE.equals(vtc.getIgnoreFull())) {
            return true;
        }
    }

    // 查询车场“车位满”策略：全部可入 / 禁止 / 部分白名单
    ParkingLotConfig lotConfig = lotConfigService.getConfig(req.tenantId, req.lotId);
    if ("ALLOW_ALL".equals(lotConfig.getFullHandling())) {
        return true;
    }
    if ("REJECT".equals(lotConfig.getFullHandling())) {
        return false;
    }
    // 部分车辆可入场：检查白名单类型
    return lotConfig.getFullWhitelistTypes().contains(req.vehicleType);
}
```

## 2.5 车牌识别匹配逻辑

### 业务说明
相机识别车牌后，系统需依次完成：黑名单校验、车辆类型/有效期判断、通道权限校验、车位满判断、一位多车判断、费用计算，最终给出放行决策。

### 输入

| 参数 | 类型 | 说明 |
|------|------|------|
| tenantId | Long | 租户 ID |
| lotId | Long | 车场 ID |
| laneId | Long | 通道 ID |
| plateNumber | String | 识别车牌 |
| plateColor | String | 车牌颜色 |
| accessType | String | ENTRY / EXIT |
| eventTime | LocalDateTime | 识别时间 |

### 输出

| 字段 | 类型 | 说明 |
|------|------|------|
| action | String | ALLOW / REJECT / CONFIRM / NO_GATE / CHARGE / FREE |
| vehicleType | String | 最终车辆类型 |
| feeAmount | BigDecimal | 应收金额（出场时） |
| reason | String | 决策原因 |
| message | String | LED/岗亭提示语 |

### 边界条件

- 白牌车辆（警车/军车/消防车）：自动放行，不收费，但记录进出日志。
- 黑名单车辆：默认拒绝，可配置为弹窗确认或记录告警放行。
- 月卡过期入场：按车场策略变临时车/拒绝/确认/不开闸。
- 无入场记录出场：按车场策略处理（默认按停留时长计费）。
- 出场时间间隔 N 分钟内重复识别：不重复计费/记录。

### 异常处理

- 车牌格式非法：记录异常并请求岗亭人工确认。
- 数据库找不到车辆但存在相似历史记录：推荐岗亭人工选择。
- 多个匹配结果：按精确匹配优先，相似匹配次之。

```java
public PlateMatchResult matchPlate(PlateMatchRequest req) {
    String plate = req.plateNumber.toUpperCase();

    // 1. 车牌格式校验
    if (!PlateUtils.isValid(plate)) {
        return PlateMatchResult.reject("INVALID_PLATE", "车牌格式异常，请人工确认");
    }

    // 2. 特殊车辆自动放行（白牌）
    if ("WHITE".equals(req.plateColor)) {
        return PlateMatchResult.freePass("SPECIAL_VEHICLE", "特殊车辆自动放行")
            .withVehicleType("SPECIAL");
    }

    // 3. 黑名单校验
    Blacklist blacklist = blacklistMapper.selectActiveByPlate(
        req.tenantId, req.lotId, plate, req.eventTime
    );
    if (blacklist != null) {
        String policy = lotConfigService.getBlacklistPolicy(req.tenantId, req.lotId);
        if ("REJECT".equals(policy)) {
            return PlateMatchResult.reject("BLACKLIST", "车辆已被限制入场");
        }
        if ("CONFIRM".equals(policy)) {
            return PlateMatchResult.confirm("BLACKLIST", "黑名单车辆，需人工确认");
        }
        if ("ALARM".equals(policy)) {
            alarmService.sendBlacklistAlarm(req.tenantId, req.lotId, plate);
        }
    }

    // 4. 查询车辆档案
    Vehicle vehicle = vehicleMapper.selectByPlateAndLot(req.tenantId, req.lotId, plate);

    // 5. 入场/出场分别处理
    if ("ENTRY".equals(req.accessType)) {
        return handleEntryFlow(req, vehicle, plate);
    } else {
        return handleExitFlow(req, vehicle, plate);
    }
}

private PlateMatchResult handleEntryFlow(PlateMatchRequest req, Vehicle vehicle, String plate) {
    // 5.1 无登记车辆：临时车
    if (vehicle == null) {
        // 车位满判断
        SpaceCalcRequest spaceReq = new SpaceCalcRequest(req.tenantId, req.lotId, req.laneId, "TEMP", req.eventTime);
        SpaceAvailabilityResult space = calcAvailableSpaces(spaceReq);
        if (space.isFull() && !allowEntryWhenFull(spaceReq)) {
            return PlateMatchResult.reject("SPACE_FULL", "车位已满");
        }
        return PlateMatchResult.allow("TEMP", "临时车，请入场");
    }

    // 5.2 通道权限校验
    if (!checkLanePermission(req.tenantId, req.lotId, req.laneId, plate, vehicle, req.eventTime)) {
        return PlateMatchResult.reject("LANE_DENIED", "该通道禁止通行");
    }

    // 5.3 车辆有效期判断
    if (vehicle.isExpired(req.eventTime)) {
        String policy = lotConfigService.getExpiryEntryPolicy(req.tenantId, req.lotId, vehicle.getType());
        switch (policy) {
            case "TEMP":
                vehicle = vehicle.asTemp();
                break;
            case "REJECT":
                return PlateMatchResult.reject("EXPIRED", "车辆已过期");
            case "CONFIRM":
                return PlateMatchResult.confirm("EXPIRED", "车辆已过期，需人工确认");
            case "NO_GATE":
                return PlateMatchResult.noGate("EXPIRED", "车辆已过期，记录但不放行");
        }
    }

    // 5.4 一位多车判断
    MultiPlateResult multi = evaluateMultiPlate(
        new MultiPlateRequest(req.tenantId, req.lotId, plate, "ENTRY", req.eventTime)
    );
    if (multi.getAction().equals("SECOND_CAR_REJECT")) {
        return PlateMatchResult.reject("MULTI_PLATE_REJECT", "一位多车，第二辆车拒绝入场");
    }
    if (multi.getAction().equals("SECOND_CAR_CONFIRM")) {
        return PlateMatchResult.confirm("MULTI_PLATE_CONFIRM", "一位多车，需人工确认");
    }
    if (multi.getAction().equals("SECOND_CAR_AS_TEMP")) {
        vehicle = vehicle.asTemp();
    }

    // 5.5 车位满判断
    SpaceCalcRequest spaceReq = new SpaceCalcRequest(
        req.tenantId, req.lotId, req.laneId, vehicle.getType(), req.eventTime
    );
    if (!canBypassFull(vehicle) && calcAvailableSpaces(spaceReq).isFull()
        && !allowEntryWhenFull(spaceReq)) {
        return PlateMatchResult.reject("SPACE_FULL", "车位已满");
    }

    return PlateMatchResult.allow(vehicle.getType(), vehicle.getTypeName() + "，请入场");
}

private PlateMatchResult handleExitFlow(PlateMatchRequest req, Vehicle vehicle, String plate) {
    // 6.1 重复出场识别过滤（N 分钟内不重复计费）
    LocalDateTime lastExit = vehicleAccessLogMapper.selectLastExitTime(
        req.tenantId, req.lotId, plate
    );
    int interval = lotConfigService.getExitIntervalMinutes(req.tenantId, req.lotId);
    if (lastExit != null && ChronoUnit.MINUTES.between(lastExit, req.eventTime) < interval) {
        return PlateMatchResult.allow(vehicle == null ? "TEMP" : vehicle.getType(), "重复识别，已放行");
    }

    // 6.2 一位多车出场处理
    MultiPlateResult multi = null;
    if (vehicle != null) {
        multi = evaluateMultiPlate(
            new MultiPlateRequest(req.tenantId, req.lotId, plate, "EXIT", req.eventTime)
        );
    }

    // 6.3 无入场记录出场
    ParkingSession session = parkingSessionMapper.selectInLotByPlate(
        req.tenantId, req.lotId, plate
    );
    if (session == null) {
        String policy = lotConfigService.getNoEntryExitPolicy(req.tenantId, req.lotId);
        if ("FREE".equals(policy)) {
            return PlateMatchResult.freePass("NO_ENTRY_FREE", "无入场记录，免费放行");
        }
        if ("REJECT".equals(policy)) {
            return PlateMatchResult.reject("NO_ENTRY", "无入场记录，禁止出场");
        }
        if ("CONFIRM".equals(policy)) {
            return PlateMatchResult.confirm("NO_ENTRY", "无入场记录，需人工确认");
        }
        // 默认按停留时长计费：使用出场时间往前推若干小时作为入场时间
        session = buildVirtualSession(req, plate);
    }

    // 6.4 计算费用
    BigDecimal fee = BigDecimal.ZERO;
    if (vehicle == null || "TEMP".equals(vehicle.getType()) || isTempDueToExpiry(vehicle, req.eventTime)) {
        FeeCalcResult feeResult = calculateParkingFee(FeeCalcRequest.builder()
            .tenantId(req.tenantId)
            .lotId(req.lotId)
            .zoneId(session.getZoneId())
            .plateNumber(plate)
            .entryTime(session.getEntryTime())
            .exitTime(req.eventTime)
            .vehicleType(vehicle == null ? "TEMP" : vehicle.getType())
            .build());
        fee = feeResult.getPayableAmount();
    }

    if (fee.compareTo(BigDecimal.ZERO) > 0) {
        return PlateMatchResult.charge(vehicle == null ? "TEMP" : vehicle.getType(), fee, "请缴费后出场");
    }

    return PlateMatchResult.allow(vehicle == null ? "TEMP" : vehicle.getType(), "自动放行");
}

private boolean checkLanePermission(Long tenantId, Long lotId, Long laneId,
                                    String plate, Vehicle vehicle, LocalDateTime time) {
    // 按车辆 > 部门 > 车场默认 的优先级校验
    LanePermission vehiclePerm = lanePermissionMapper.selectByVehicle(
        tenantId, lotId, vehicle.getId(), laneId, time
    );
    if (vehiclePerm != null) {
        return vehiclePerm.allowsAccess();
    }
    if (vehicle.getDepartmentId() != null) {
        LanePermission deptPerm = lanePermissionMapper.selectByDepartment(
            tenantId, lotId, vehicle.getDepartmentId(), laneId, time
        );
        if (deptPerm != null) {
            return deptPerm.allowsAccess();
        }
    }
    // 无单独配置：默认允许
    return true;
}
```

## 2.8 性能与安全提示

1. **缓存**：`parking_lot`、`parking_zone`、`fee_rule`、`vehicle` 等热数据使用 Redis 缓存，缓存 key 必须包含 `tenant_id`。
2. **锁粒度**：车位余量锁按 `tenant:lot:zone` 加锁，避免全平台锁竞争。
3. **幂等**：车辆入场/出场接口须带唯一请求号，防止相机重复上报导致重复计费。
4. **敏感信息**：操作日志中的 `before_value/after_value` 不得包含支付密钥、手机号明文、身份证号明文。
5. **事务**：收费计算与优惠券核销、积分扣减、商家余额扣减必须在同一数据库事务内完成，任一失败整体回滚。
