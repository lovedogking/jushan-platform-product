## 2. 数据源配置

```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/jushan_platform?useUnicode=true&characterEncoding=UTF-8&serverTimezone=Asia/Shanghai
    username: root
    password: root
    driver-class-name: com.mysql.cj.jdbc.Driver
    hikari:
      maximum-pool-size: 10
      minimum-idle: 2
      idle-timeout: 300000
      connection-timeout: 10000
```

生产环境：密码等敏感信息通过环境变量注入，禁止写入配置文件。

## 3. Redis 配置

```yaml
spring:
  data:
    redis:
      host: localhost
      port: 6379
      password:
      database: 0
      timeout: 3000ms
      lettuce:
        pool:
          max-active: 8
          max-idle: 8
          min-idle: 0
          max-wait: -1ms
```

Redis 用于：

- Sa-Token 会话存储
- 限流
- 分布式锁
- 热点缓存
- **Webhook 事件幂等去重**（`webhook:event:{eventId}`，24 小时过期）

## 4. Sa-Token 配置

```yaml
sa-token:
  token-name: Authorization
  token-prefix: Bearer
  timeout: 86400
  active-timeout: 1800
  is-concurrent: true
  is-share: false
  token-style: tik
  is-log: false
  is-print: false
  is-read-header: true
  is-read-cookie: false
  is-read-body: false
```

- Token 从 `Authorization: Bearer <token>` 读取。
- 关闭 Cookie/Body 来源，防止 Token 来源混乱。

## 5. Device Access 客户端配置

```yaml
jushan:
  device-access:
    base-url: http://localhost:8081
    connect-timeout: 3000
    read-timeout: 12000
    # 预留接口开关（一期 false，待 Device Access v1.0 冻结后开启）
    enable-gate-control: false
    enable-display-control: false
    enable-voice-control: false
```

| 配置项 | 说明 |
|---|---|
| `base-url` | Device Access 服务地址 |
| `connect-timeout` | TCP 连接超时（毫秒） |
| `read-timeout` | 响应读取超时（毫秒） |
| `enable-gate-control` | 是否启用开闸/关闸控制（预留） |
| `enable-display-control` | 是否启用显示屏控制（预留） |
| `enable-voice-control` | 是否启用语音控制（预留） |

生产环境通过环境变量覆盖：

```bash
JUSHAN_DEVICE_ACCESS_BASE_URL=https://device-access.internal
JUSHAN_DEVICE_ACCESS_CONNECT_TIMEOUT=3000
JUSHAN_DEVICE_ACCESS_READ_TIMEOUT=12000
JUSHAN_DEVICE_ACCESS_ENABLE_GATE_CONTROL=false
JUSHAN_DEVICE_ACCESS_ENABLE_DISPLAY_CONTROL=false
JUSHAN_DEVICE_ACCESS_ENABLE_VOICE_CONTROL=false
```

## 6. Webhook 接收配置

平台接收 Device Access 事件推送的端点配置：

```yaml
jushan:
  device-webhook:
    # 接收端点已内置于平台（/api/v1/device-webhook/events），无需额外端口配置
    # 以下配置用于事件处理
    event-ttl-hours: 24          # 幂等去重保留时间
    max-concurrent-events: 50  # 最大并发处理事件数
```

> **安全注意**：Webhook 端点不经过 Sa-Token 鉴权（Device Access 作为服务端调用），
> 生产环境需通过 Nginx IP 白名单或请求签名验证来源。

## 6. Flyway 配置

```yaml
spring:
  flyway:
    enabled: true
    locations: classpath:db/migration
    clean-disabled: true
```

- 迁移脚本位于 `parking-boot/src/main/resources/db/migration/`。
- `clean-disabled: true` 防止生产环境误清库。
- 已发布迁移禁止修改。

## 7. 日志配置

```yaml
logging:
  level:
    root: INFO
    com.jushan: DEBUG
  pattern:
    console: "%d{yyyy-MM-dd HH:mm:ss.SSS} [%thread] [%X{traceId}] %-5level %logger{36} - %msg%n"
```

- 日志中通过 `%X{traceId}` 输出 TraceId。
- 禁止在日志中输出密码、Token、支付密钥、敏感个人信息明文。

## 8. Docker Compose 环境变量

| 变量 | 默认值 | 说明 |
|---|---|---|
| `DB_ROOT_PASSWORD` | `root` | MySQL root 密码 |
| `DB_NAME` | `jushan_platform` | 默认数据库名 |
| `DB_USERNAME` | `jushan` | MySQL 应用账号 |
| `DB_PASSWORD` | `jushan_dev` | MySQL 应用密码 |
| `DB_PORT` | `3307` | MySQL 宿主机端口 |
| `REDIS_PORT` | `6378` | Redis 宿主机端口 |
| `RABBITMQ_USERNAME` | `guest` | RabbitMQ 用户名 |
| `RABBITMQ_PASSWORD` | `guest` | RabbitMQ 密码 |
| `RABBITMQ_VHOST` | `/` | RabbitMQ 虚拟主机 |
| `RABBITMQ_AMQP_PORT` | `5672` | RabbitMQ AMQP 端口 |
| `RABBITMQ_MGMT_PORT` | `15672` | RabbitMQ 管理后台端口 |
| `NGINX_PORT` | `8088` | Nginx 宿主机端口 |

## 9. 敏感配置红线

以下信息**禁止**写入任何提交到仓库的配置文件：

- 微信支付商户号、API 密钥、证书私钥
- 支付回调密钥
- 数据库 root 密码（生产）
- Sa-Token 密钥（如自定义）
- Device Access 服务间认证密钥
- 第三方服务 API 密钥

生产环境统一通过环境变量或外部密钥管理服务注入。
