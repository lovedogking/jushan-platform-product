本模块是 parking-framework / parking-system 之上的可执行 jar 装配层，不承载业务逻辑，仅做外部依赖的自动装配与环境拼装：
- 入口 `ParkingApplication` 通过 `@SpringBootApplication(scanBasePackages = "com.jushan")` 统一扫描 framework/common/各业务模块。
- 配置集中在 `config/`：`AppConfig`、`AppProperties`、`ProdConfigValidator` 提供通用 Bean 与生产校验；`MyBatisConfig` 条件化注册 `@MapperScan("com.jushan.**.mapper")` 与 MyBatis-Plus 分页插件（`PaginationInnerInterceptor`，最大页 200），并通过 `jushan.scan-mappers=false` 在轻量测试中禁用以避免无 DataSource 时启动失败。
- 健康检查 `health/ReadinessHealthIndicator` 实现 Actuator readiness probe，使用 `ObjectProvider` 优雅降级未配置的 MySQL/Redis 依赖，按 T07/T08/T23 阶段逐步扩展。
- 数据库迁移由 Flyway 驱动，SQL 脚本位于 `resources/db/migration/VYYYYMMDDNNN__*.sql`，命名含日期+序号，覆盖租户、设备、计费、审计等全量 DDL。
- 配置文件采用 profile 分层：`application.yml` 为共享基线，`application-local.yml`/`application-test.yml`/`application-prod.yml`/`application-docker.yml` 分别覆盖本地、测试、生产、容器运行态，敏感值通过环境变量注入。
- 测试体系基于 `TestcontainersBaseTest` + `@ServiceConnection` 启动 MySQL 8.4 容器，配合 WireMock 模拟 Device Access HTTP 下游，RabbitMQ/Redis 基础设施测试位于对应子包。
