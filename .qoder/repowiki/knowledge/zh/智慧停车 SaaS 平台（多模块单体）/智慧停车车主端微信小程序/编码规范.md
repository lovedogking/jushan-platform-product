- HTTP 响应遵循 R01 冻结契约：业务成功以 `code===0` 标识，错误通过 `createApiError` 附带 `code/status/message/traceId` 字段向上抛出。
- Token 持久化键名固定为 `jushan_access_token`，用户信息键名为 `ownerInfo`，均通过 `wx.getStorageSync` / `removeStorageSync` 读写。
- GET/DELETE 方法通过 `Object.keys(params).filter(...).map(encodeURIComponent)` 手动拼接查询字符串，过滤 undefined/null 值。
- 401 响应触发 `app.logout()` 清除本地登录态，403 则不清除 Token 直接拒绝。
