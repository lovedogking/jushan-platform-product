模块为独立的前端工程，入口 `src/main.ts` 依次挂载 Pinia、vue-router 与 Ant Design Vue（全局主题在 `App.vue` 中通过 `a-config-provider` 配置）。路由采用懒加载定义于 `src/router/index.ts`，包含 `/login`、根布局 `/` 下重定向到 `/monitor` 以及 404 兜底；`beforeEach` 守卫统一校验 `localStorage` 中的 `jushan_access_token`，未登录时带 `redirect` 参数跳转登录页。

分层结构：
- `api/`：按业务域拆分 HTTP 客户端（`auth.ts`、`monitor.ts`），类型集中在 `monitor-types.ts`；所有请求经 `utils/request.ts` 封装的 axios 实例，统一处理 Token 注入、NProgress 进度条、401 幂等跳转与 `ApiError` 抛出。
- `stores/monitor.ts`：Pinia store 管理监控状态，由视图组件订阅。
- `utils/websocket.ts`：`MonitorWebSocketClient` 类封装 STOMP over WebSocket，实现指数退避自动重连、断线恢复订阅、连接状态回调，并通过 `/topic/booth/{parkingLotId}` 前缀订阅事件、车位、设备、告警四类消息。
- `layout/`、`views/`：页面级 `.vue` 组件，`error/404.vue` 作为兜底。
- `styles/`：SCSS 变量通过 Vite `additionalData` 全局注入，避免 `@import` 弃用警告。

构建与代理由 `vite.config.ts` 集中配置：开发端口 3001，`/api` 重写转发至 `http://localhost:8080`，`/ws` 透传 WebSocket；生产构建使用 `manualChunks` 将 vue/vue-router/pinia 与 axios 拆包。
