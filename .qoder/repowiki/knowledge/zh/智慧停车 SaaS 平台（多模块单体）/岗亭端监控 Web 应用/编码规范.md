- HTTP 请求统一走 `utils/request.ts` 导出的 `get/post/put/delete` 方法，禁止在业务代码中直接 import axios。
- Token 存储键名统一使用常量 `'jushan_access_token'`，并在请求拦截器中以 `Authorization: Bearer ${token}` 形式注入。
- 路由组件一律采用 `() => import('@/views/...')` 动态导入，配合 `meta.title` 控制浏览器标题。
- WebSocket 客户端以类封装并暴露 `connect()/disconnect()` 生命周期，内部维护 `reconnectAttempts` 与指数退避延迟，通过 `handlers` 回调向外部推送连接状态与消息。
- API 响应体遵循 `{ code, message, data, traceId }` 契约，`code === 0` 视为成功，其余情况由拦截器统一抛 `ApiError` 并提示用户。
