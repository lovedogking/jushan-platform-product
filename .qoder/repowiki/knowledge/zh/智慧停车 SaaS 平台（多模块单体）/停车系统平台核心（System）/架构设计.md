本模块作为 parking-system 的 Java 应用入口层，按领域拆分为多个子包（tenant_auth、tenant_management、device_management、parking_lot_lane、parking_operations、billing_rule、wx_integration、monitor_alert、audit_log、external_client），每个子包自包含 controller→service→mapper→entity 的完整链路；跨子域协作通过以下机制实现：
- 对外 HTTP 边界由 `controller/` 下的各业务 Controller 暴露，统一经 Sa-Token 鉴权与审计拦截。
- 共享基础设施集中在 `config/`（如 SaTokenConfig、Redis 配置、MyBatis-Plus 分页等），所有子域共用同一套数据源与事务策略。
- 对硬件层的唯一出口是 `client/DeviceAccessClient`，被 device_management 与 parking_operations 共同调用以下发 T20/T21/T24/T25 指令。
- 识别事件总线位于 `event/`，`RecognitionEventPublisher` 由入场流程发布，`RecognitionEventConsumer` 在本地消费并落库 `RecognitionEventLog`，同时 `PlateStandardizer` 提供跨子域的车牌标准化能力。
- WebSocket 推送由 `ws/BoothWebSocketPublisher` 集中封装，被 monitor_alert 与 parking_operations 复用，按岗亭维度广播监控快照与放行结果。
- 计费引擎 `BillingEngine` 与 `BillingRuleService` 为 parking_operations 与 WxParkingFeeController 共享的纯计算层，不依赖持久化。
