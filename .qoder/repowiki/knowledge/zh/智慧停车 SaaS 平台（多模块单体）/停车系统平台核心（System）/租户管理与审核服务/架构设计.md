模块采用标准的 Controller → Service → Mapper 三层结构：
- `TenantController` 暴露 `/admin/tenants` 下的 GET（分页列表、详情）与 POST（审核/启停）端点，通过 Sa-Token 的 `@SaCheckPermission("tenant:read"|"tenant:write")` 做权限控制，仅超级管理员与平台运营可访问。
- `TenantService` 承载全部业务：客户自助注册（校验企业名/手机号唯一性、创建待审 `sys_user` + `tenant` 并在事务中回填关联）、状态机式审核（`validateStateTransition` + 条件更新防并发覆盖）、禁用时批量撤销该租户下所有用户会话（调用 `StpUtil.logout` + `StpInterfaceImpl.clearCache`），以及将操作写入 `TenantAuditLog`。
- `Tenant` 是 MyBatis-Plus 实体，映射到 `tenant` 表，字段包含企业名称、联系人、电话、状态、配额上限等；VO 层通过 `TenantVO` 返回脱敏后的手机号与管理员用户名。
依赖方向单向向下：Controller 依赖 Service，Service 依赖 `TenantMapper` / `SysUserMapper` / `TenantAuditLogMapper` 与 `StpInterfaceImpl`，不反向依赖上层。
