本模块采用典型的 Controller → Service → Mapper 三层结构：
- `DeviceController` 暴露 `/admin/devices` REST API，使用 Sa-Token 的 `@SaCheckPermission("device:read"|"device:manage")` 做细粒度权限控制，所有请求通过 parkingLotId 推导租户范围，不信任前端传入 tenantId。
- `DeviceService` 承载全部业务逻辑：设备创建/更新/启停、车道绑定（T21）、厂商/型号查询、设备校时（T25）、开闸占位（P001）、状态查询与快照（T24）。通过 `ParkingLotScopeResolver` + `getDeviceWithAuth` / `getParkingLotWithAuth` 实现基于停车场的租户隔离；通过 `DeviceAccessClient` 调用 Device Access v0.2 远程接口；通过 `DeviceStatusSnapshotMapper` / `SysAuditLogMapper` / `DeviceCommandAuditMapper` 持久化状态快照与审计日志。
- `Device` 是 MyBatis-Plus 实体（`@TableName("device")`），作为平台设备主数据源，`device_sn` 在同厂商内唯一且禁止前端直接传入。
依赖方向单向：Controller → Service → (Mapper + DeviceAccessClient + ScopeResolver)，Service 内部再组合 ParkingLot/ParkingLane/Vendor/Model 等多表校验，保证跨实体一致性。
