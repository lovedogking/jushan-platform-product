模块按职责拆分为两个子包：
- `client`：面向 Device Access v0.2 的 HTTP 客户端抽象。`DeviceAccessClient` 定义接口（status/syncTime/openGate），`DeviceAccessClientImpl` 基于 `RestTemplate` 实现，统一通过 `execute(path, method, deviceSn, typeRef)` 发起请求并解析 `DeviceAccessResponse<T>`；内置内存级熔断器（连续失败阈值 + 恢复窗口）和 Micrometer 指标（calls.total / calls.errors / latency / circuit_breaker.state），所有异常归一为 `BusinessException`，不信任自动重试。
- `event`：识别事件总线。`RecognitionEventPayload` + `EventSource` 构成平台内部标准事件模型；`RecognitionEventPublisher` 先持久化到 `recognition_event_log`，再经 `MessageEnvelope` 投递到 RabbitMQ（`ObjectProvider<RabbitTemplate>` 注入以支持 MQ 不可用降级），同时可选推送至 `BoothWebSocketPublisher`；`RecognitionEventConsumer` 在 `@RabbitListener` 中执行消息级幂等（`MessageIdempotency`）、业务校验（设备/停车场/车道存在性与方向匹配、跨租户一致性）、车牌标准化（`PlateStandardizer`），随后委托 `EntryService` / `ExitService` 处理入场或出场，最终更新日志状态；`PlateStandardizer` 提供去空白、全角转半角、大写规范化及蓝牌/绿牌/港澳牌照正则校验。
依赖方向单向向外：本模块依赖 `framework.mq`、`common.BusinessException`、`system.service.*`、`system.mapper.*`、`system.ws.*`，不被上层反向依赖。
