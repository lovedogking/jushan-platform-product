- 对外统一通过 com.jushan.common.R<T> 包装返回值，业务异常使用 BusinessException(CommonErrorCode.XXX, message) 抛出
- 可选外部依赖（AuditService、StringRedisTemplate）通过 @Autowired(required = false) 注入并在方法内判空降级，保证主流程不因依赖缺失而中断
- 登录失败计数使用 RedisKeyPrefix.LOGIN_FAIL + username + ":" + ip 作为 Key，配合 expire 实现滑动窗口限流
- 所有敏感操作（登录、改密、登出）均通过 recordLoginLog 或 StpUtil 调用进行审计记录，且审计失败 catch 后仅打日志不阻断主流程
