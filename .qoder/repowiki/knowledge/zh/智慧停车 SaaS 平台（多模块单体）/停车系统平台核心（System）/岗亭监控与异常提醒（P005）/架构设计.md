本模块遵循标准三层结构：`BoothMonitorController` 作为 HTTP 入口，通过 `@SaCheckPermission("booth:monitor")` 做权限校验，仅转发参数并返回统一 `R<T>` 响应；业务逻辑集中在 `BoothMonitorService`，负责聚合 `ParkingLotMapper`/`ParkingLaneMapper`/`DeviceMapper`/`RecognitionEventLogMapper` 的数据，并通过 `DeviceService` 调用外部设备访问接口获取实时状态，同时委托 `MonitorAlertService` 完成告警的生成与查询；`MonitorAlert` 是持久化实体，映射到 `monitor_alert` 表，定义四种告警类型常量（DEVICE_OFFLINE / LOT_FULL / LOT_DISABLED / RECOGNITION_FAIL）和两种严重级别常量（WARNING / CRITICAL）。依赖方向单向：Controller → Service → Mapper + 其他 Service，Service 内部再反向调用 `MonitorAlertService` 以触发告警（如设备离线、车位已满、停车场停用），并在 `getSnapshot` 中统一组装成 `BoothMonitorSnapshotVO` 返回前端。
