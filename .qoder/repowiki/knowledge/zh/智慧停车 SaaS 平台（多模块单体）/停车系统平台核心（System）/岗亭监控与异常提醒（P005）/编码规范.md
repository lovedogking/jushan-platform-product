- Controller 方法一律使用构造器注入依赖，并通过 `@SaCheckPermission` 注解声明资源级权限，返回值统一封装为 `R<T>`。
- Service 层在访问租户数据前统一调用 `DataScope.validateTenantMatch` 与 `ParkingLotScopeResolver.validateAccess` 进行租户与数据范围双重校验。
- MyBatis-Plus 查询统一使用 `LambdaQueryWrapper` 构建条件，并按主键或时间字段排序后追加 `LIMIT` 限制结果集大小。
- 实体类将枚举值以 `public static final String` 常量形式暴露（如 TYPE_*、SEVERITY_*），而非 Java enum。
