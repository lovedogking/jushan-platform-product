- 常量集中声明于 Service 类内（如 RESULT_SUCCESS/FAILED/UNCERTAIN、ACTION_PROXY_START/STOP、TARGET_TYPE_TENANT），避免魔法字符串散落。
- 对外写审计 API 与内部持久化 API 分离：`writeAuditLog` 自动从 `TenantContext` 填充操作人与代理状态，`writeAuditLogDirect` 接受全量参数并由调用方决定是否 fail-close。
- 异常统一通过 `BusinessException(CommonErrorCode.XXX, message)` 抛出，错误码来自 `CommonErrorCode` 枚举而非硬编码字符串。
- 可选查询参数一律使用 `@RequestParam(required = false)` 并在 Service 层以 `!= null && !isBlank()` 判断后追加到 `LambdaQueryWrapper`，时间参数用 try-catch 包裹 `LocalDateTime.parse` 忽略非法格式。
- 实体 getter/setter 保持手写风格且对可空字段做默认值处理（如 `getIsProxy()` 返回 0 当值为 null）。
