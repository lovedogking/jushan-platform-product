- 对外暴露的枚举值（规则类型 HOURLY/FIXED/NO_FEE、状态 ENABLED/DISABLED）统一以类内 public static final String 常量定义，并在 validateRuleType/validateStatus 中集中校验。
- 所有写方法标注 `@Transactional`，并在方法入口通过 `DataScope.requireTenantUser()` 与 `TenantContext.requireUserId()` 从会话推导租户与用户，禁止直接使用请求中的 tenantId。
- 资源访问前统一调用私有辅助方法 `getRuleWithAuth` / `getParkingLotWithAuth`，内部依次执行 NOT_FOUND 检查、`DataScope.validateTenantMatch` 租户匹配、`scopeResolver.validateAccess` 停车场级授权校验。
- 业务异常通过抛出 `BusinessException(CommonErrorCode.XXX, message)` 表达，错误码来自 `CommonErrorCode` 枚举而非硬编码字符串。
- VO 转换集中在 Service 的 `toVO` / `toVersionVO` 私有方法中，使用 Hutool `BeanUtil.copyProperties` 后补充关联字段（如当前生效版本详情、中文描述）。
- 日志记录采用 `private static final Logger log = LoggerFactory.getLogger(...)` 模式，关键路径（创建/更新/切换）均输出结构化 info 日志。
