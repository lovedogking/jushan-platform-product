- 所有写操作均使用 `@Transactional(rollbackFor = Exception.class)` 标注，保证入场/出场流程的原子性。
- 状态变更一律通过 `LambdaUpdateWrapper` 进行条件更新（如 `eq(status, 'PARKING')`），禁止整实体覆盖，防止并发覆盖。
- 对外部传入的 `tenantId` 不直接信任，而是从可信的停车记录或停车场推导后写入实体。
- 车牌号统一经 `PlateStandardizer` 标准化后存入 `standardizedPlate` 字段，避免脏数据。
- 容量更新采用 SQL 原子表达式（`setSql("current_vehicles = current_vehicles + 1")`）而非先查后写，避免竞态。
- WebSocket 推送封装在独立私有方法中且捕获异常仅打 warn 日志，确保推送失败不影响主业务事务。
