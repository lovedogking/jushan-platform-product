- 对外暴露的统一响应体使用 `com.jushan.common.R`，异常处理器中通过 `.traceId(MDC.get(TraceIdFilter.MDC_KEY))` 自动附加链路 ID。
- 可插拔能力通过 `@ConditionalOnClass` + `@ConditionalOnProperty` 组合控制 Bean 装配，确保依赖缺失或显式关闭时应用仍可启动。
- 外部中间件不可用时的降级策略：使用 `ObjectProvider<T>` 懒获取连接工厂，取不到则记录 warn 日志并返回空操作对象，不阻塞启动。
- 安全相关类以 P0 红线注释明确禁止行为（如 WebSocket 直连 Device Access、MQ 不声明 Device Access 资源、异常不泄露堆栈）。
- HTTP 请求生命周期横切采用 Filter → Interceptor → Advice 三层分工：Filter 管 TraceId，Interceptor 管 TenantContext，Advice 做防御性校验。
