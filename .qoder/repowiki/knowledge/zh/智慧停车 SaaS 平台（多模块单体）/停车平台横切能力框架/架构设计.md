基于 Spring Boot Starter 的横切能力库，按关注点划分为独立子包：
- `web`：`TraceIdFilter`(OncePerRequestFilter) + `TraceIdResponseBodyAdvice` 注入 MDC/X-Trace-Id；`GlobalExceptionHandler`(@RestControllerAdvice) 将参数校验、Sa-Token 认证/授权、Spring 内置异常统一收敛为 `com.jushan.common.R` 响应。
- `auth`：`SaTokenConfig` 注册 Sa-Token 拦截器并排除公开路径；`TenantContext`(ThreadLocal) + `TenantContextInterceptor`(MVC Interceptor) 在请求进入时填充租户上下文，`TenantContextAdvice` 仅做防御性校验不主动填充。
- `lock`：`DistributedLock` 注解 + `RedisDistributedLock` 基于 Redis SETNX 实现方法级分布式锁。
- `mq`：`RabbitMqConfig` 声明平台内部 TopicExchange/DirectExchange(DLX)/Queue 及 JSON 序列化，通过 `ObjectProvider<ConnectionFactory>` 在 RabbitMQ 不可用时降级为空操作；`MessageEnvelope`/`MessageIdempotency`/`RedisMessageIdempotency` 提供消息幂等能力。
- `redis`：`RedisConfig` + `CacheNames`/`RedisKeyPrefix` 集中管理 Redis 连接与 Key 前缀。
- `ws`：`WebSocketConfig` 启用 STOMP over WebSocket，握手阶段由 `WsAuthHandshakeInterceptor` 鉴权，通道层由 `WsChannelAuthInterceptor` 做数据范围校验，`WsSessionContext` 承载会话上下文。
- `config`：`WebMvcConfig` 统一 MVC 配置，`DeviceAccessConfig`/`DeviceAccessProperties` 暴露设备访问开关。
依赖方向单向指向 `parking-common` 和 Spring 生态（sa-token-spring-boot3-starter、spring-boot-starter-amqp/websocket/data-redis），自身不引入业务领域模型。
