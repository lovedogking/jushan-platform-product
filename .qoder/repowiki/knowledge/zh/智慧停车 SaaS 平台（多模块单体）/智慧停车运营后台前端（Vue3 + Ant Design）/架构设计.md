单页应用，入口 `src/main.ts` 依次挂载 Pinia、vue-router、Antd 全局组件库并调用 `useAuthStore().init()` 恢复登录态。
- 路由层：`src/router/index.ts` 以 `constantRoutes` 集中声明所有静态路由，使用懒加载 `() => import(...)` 拆分页面 chunk；`beforeEach` 守卫实现白名单 `/login` 放行、未登录重定向到 `/login?redirect=...`、首次进入时拉取用户信息。
- 状态层：`src/stores/` 下按领域划分 Pinia store（auth、app、tabs），其中 `auth.ts` 通过 `localStorage` 持久化 `jushan_access_token`，并提供 `validateAndSetToken` 校验 token 非空再落盘。
- 网络层：`src/utils/request.ts` 封装 axios 实例，统一处理 NProgress 进度条、401 防抖跳转、业务码 `code===0` 成功分支、以及 `ApiError` 异常对象；各业务 API 集中在 `src/api/*.ts` 中仅暴露 `get/post/put/delete` 调用，不直接写 URL。
- 视图层：`src/views/<module>/index.vue` 一文件一页面，布局壳在 `src/layout/index.vue`，错误页拆分为 403/404/500 三个子路由。
- 构建与样式：`vite.config.ts` 配置 `@` 路径别名、开发代理 `/api -> http://localhost:8080`、SCSS 全局注入 `variables.scss`，并通过 Rollup `manualChunks` 将 vue/vue-router/pinia、ant-design-vue、axios/dayjs/nprogress 拆为独立 vendor chunk。
