- API 调用统一走 `src/api/*.ts` 中的函数，内部复用 `src/utils/request` 的 get/post/put/delete，禁止在组件中直接引入 axios。
- 路由定义集中放在 `src/router/index.ts` 的 `constantRoutes` 数组中，使用 `component: () => import(...)` 懒加载并按 `meta.title` / `meta.icon` 驱动菜单渲染。
- 认证相关逻辑集中在 `stores/auth.ts` 的 Pinia store 内，token 写入必须经过 `validateAndSetToken` 校验非空字符串后再落盘 localStorage。
- HTTP 响应体约定 `code === 0` 为业务成功，其余一律构造 `ApiError` 抛出，由 request 拦截器统一展示 message 或触发 401 跳转。
- 401 场景使用 `isRedirectingLogin` 标志位防止并发请求重复跳转登录页，并在请求拦截器中对 `/auth/login` 排除 Bearer Token 注入。
