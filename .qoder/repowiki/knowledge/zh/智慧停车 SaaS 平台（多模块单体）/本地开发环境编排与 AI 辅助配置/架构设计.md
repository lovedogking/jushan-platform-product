本模块由两个相互独立的子域组成：
- `docker/`：仅包含 Nginx 站点配置（`nginx.conf` + `conf.d/default.conf`）和 `mysql/init/.gitkeep` 占位目录；Nginx 作为本地开发入口，将 `/api/*` 通过 rewrite 去掉前缀后转发到宿主机 `host.docker.internal:8080` 的 Spring Boot 后端，同时透传 `X-Trace-Id`、WebSocket `Upgrade` 头以及 `/actuator/*` 健康检查路径，静态前端资源在开发阶段走 Vite dev server，生产路径已注释预留。
- `.codex/` 与 `.agents/skills/`：Codex CLI 的仓库级配置中心，`config.toml` 声明五个只读 agent（repo_explorer、reviewer、security_reviewer、test_analyst、hard_debugger），各自指向同目录下的 `.toml` 配置文件；`.agents/skills/` 下按业务域组织可插拔 skill（device-access-contract-review、parking-payment-security-review、parking-saas-risk-review），每个 skill 内含 `SKILL.md` 与 `agents/openai.yaml` 描述文件。
依赖方向单向向外：本模块不引入任何应用代码，仅被 docker-compose 或 Codex CLI 消费。
