#### 3.2 业务规则

**三级管理员绑定**：
- 一级管理员（level=1）：tenant_id 可为 NULL，管理全平台
- 二级管理员（level=2）：company_id 必填，管理该公司下全部车场

**密码策略**：
- BCrypt 加密
- 登录失败 5 次后锁定 30 分钟（status=2, lock_until=now+30min）
- 登录成功重置 login_fail_count=0

**重置密码**：
- 生成随机 8 位密码（字母+数字）
- BCrypt 加密后存储
- 返回明文给用户（仅一次）

**权限矩阵**：
- 保存时先删除该角色旧权限，再批量插入新权限（事务）
- 登录后缓存到 Redis：Key=`auth:permissions:{userId}`, TTL=24h

### Step 4：授权码管理（TASK-0104）

#### 4.1 实体类
`SysAuthCode` 继承 BaseEntity。

#### 4.2 业务规则

**生成规则**：
- 格式：XXXX-XXXX-XXXX-XXXX（16位字母数字，大写，4位一组）
- 使用 SecureRandom 生成，排除易混淆字符（0, O, I, L）
- 批量生成时校验不重复（uk_code）

**状态机**：
- 0未使用 → 1已激活 → 2已过期 / 3已禁用

**激活校验**：
- 当前日期在 valid_start 和 valid_end 之间
- used_count < max_use_count
- status = 0

**激活成功**：
- status=1, tenant_id=当前租户ID, activated_by=当前用户ID, activated_at=now, used_count++

**权限控制**：
- 批量生成：仅 level=1 可访问
- 激活：仅 level=2 可访问（且只能激活未使用的码）
- 列表/导出：level=1 看全部，level=2 看本租户已激活的码

#### 4.3 Controller 接口
- `POST /api/v1/auth-codes/batch` - 批量生成授权码（仅一级管理员）
- `GET /api/v1/auth-codes` - 分页列表
- `POST /api/v1/auth-codes/{code}/activate` - 激活授权码（二级管理员）
- `PUT /api/v1/auth-codes/{id}/disable` - 禁用授权码
- `GET /api/v1/auth-codes/export` - 导出 Excel

#### ✅ Step 4 验收标准
- [ ] 过期/已用完/已禁用的授权码无法激活
- [ ] 激活成功后，租户功能版本正确写入
- [ ] Excel 导出包含授权码、状态、有效期、激活人、激活时间

## 🔧 全局代码规范

### 后端规范
- **包名**：`com.jushan.platform.modules.{module}`
- **实体**：`XxxEntity extends BaseEntity`，`@TableName("sys_xxx")`
- **Mapper**：`XxxMapper extends BaseMapper<XxxEntity>`
- **Service**：`XxxService extends IService<XxxEntity>`，`XxxServiceImpl extends ServiceImpl`
- **Controller**：`@RestController`、`@RequestMapping("/api/v1/xxx")`、`@Validated`
- **DTO**：`XxxCreateCmd`、`XxxUpdateCmd`（Jakarta Validation 注解：@NotBlank、@Size、@Pattern）
- **VO**：`XxxVO`、`XxxTreeVO`
- **转换**：使用 MapStruct（XxxConverter）或 BeanUtils
- **异常**：`BusinessException(String message)`，`GlobalExceptionHandler` 捕获
- **分页**：MyBatis-Plus Page，Controller 接收 PageQuery（pageNum, pageSize），返回 PageResult
- **注释**：使用中文，类注释包含作者、日期、功能描述

### 前端规范
- **API**：按模块分文件，`src/api/company.ts`、`src/api/account.ts`、`src/api/auth.ts`
- **命名**：组件名大驼峰，页面以 Manage/Modal/View 结尾
- **表单校验**：Ant Design Vue rules，必填项红色星号
- **表格**：统一分页（a-pagination），统一空状态
- **权限**：按钮级使用 `v-permission` 指令或 `PermissionButton` 组件

### 安全规范
- 所有 POST/PUT/DELETE 接口（除登录外）必须校验登录状态
- 密码禁止明文存储（BCrypt 加密）
- 敏感字段（phone、password、apiKey）在日志和返回前脱敏
- 前端传入的 tenantId 不可信，必须从 TenantContext 获取
