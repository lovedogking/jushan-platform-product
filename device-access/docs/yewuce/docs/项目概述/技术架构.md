# 技术架构

> 文档状态：**ACTIVE**  
> 适用范围：jushan-platform  
> 最后更新：2026-07-14

本文档记录项目实际采用的技术栈，基于 `pom.xml`、`admin-web/package.json`、`booth-web/package.json` 和 `miniapp/app.json` 等真实配置文件整理。

---

## 1. 后端技术栈

| 领域 | 技术 | 版本/备注 |
|------|------|-----------|
| 语言/运行时 | Java 21 LTS | |
| 框架 | Spring Boot | 3.5.16 |
| 构建工具 | Maven | 多模块聚合，模块化单体 |
| ORM | MyBatis-Plus | 3.5.9 |
| 数据库 | MySQL | 8.4 |
| 缓存 | Redis | 7.x |
| 权限认证 | Sa-Token | 1.42.0 |
| 消息队列 | RabbitMQ | 4.x（平台内部业务事件、设备事件异步处理） |
| 实时通信 | Spring WebSocket（STOMP） | 岗亭端实时推送 |
| 数据库迁移 | Flyway | 10.22.0 |
| 容器化 | Docker Compose | 本地开发环境 |
| 测试框架 | JUnit 5 + Mockito + Testcontainers | 基础设施集成测试 |
| 外部设备接入 | HTTP Client（RestTemplate） | 调用 Device Access HTTP 接口；Webhook 接收设备事件推送 |

## 2. 前端技术栈

| 工程 | 技术 | 备注 |

| admin-web | Vue 3 + TypeScript + Vite + Pinia + Ant Design Vue 4 | 总后台 / 运营端 |
| booth-web | Vue 3 + TypeScript + Vite + Pinia + Ant Design Vue 4 | 岗亭端 |

---

## 3. 基础设施

| 组件 | 用途 |
|------|------|
| Nginx | 反向代理、静态资源、HTTPS 终端 |
| MySQL | 业务数据持久化 |
| Redis | 会话缓存、限流、分布式锁、热点数据、Webhook 事件幂等去重 |
| RabbitMQ | 平台内部异步事件（如识别事件分发、支付回调处理） |
| Docker Compose | 本地开发环境编排 |

### 外部依赖

| 服务 | 用途 | 接入方式 | 当前状态 |
|------|------|----------|----------|
| Device Access | 设备通信、协议适配、事件转换 | HTTP 调用 + Webhook 接收 | v0.2 已提供设备管理、校时、状态查询；v1.0 目标提供事件推送、开闸控制 |
| P云开放平台 | 停车支付聚合 | HTTP API | 已对接 |

> **Device Access 边界**：平台侧只维护设备业务台账，通过 `DeviceAccessClient` HTTP 调用 Device Access 接口；设备识别事件通过 Webhook 推送到平台 `/api/v1/device-webhook/events`。

## 4. 模块依赖关系

```
┌─────────────────────────────────────────────┐
│              parking-boot                   │
│              启动与装配                      │
└──────────────────┬──────────────────────────┘
                   │ 依赖
┌──────────────────▼──────────────────────────┐
│              parking-system                 │
│              业务模块                        │
└──────────────────┬──────────────────────────┘
                   │ 依赖
┌──────────────────▼──────────────────────────┐
│             parking-framework               │
│        横切能力（租户、权限、异常、Trace）    │
└──────────────────┬──────────────────────────┘
                   │ 依赖
┌──────────────────▼──────────────────────────┐
│              parking-common                 │
│        公共类型、响应、异常、工具类          │
└─────────────────────────────────────────────┘
```

禁止跨模块直接操作 Mapper/实体，禁止循环依赖。

---

## 5. 版本与升级原则

- 后端框架版本以根 `pom.xml` 为准。
- 前端依赖版本以各工程 `package.json` 为准。
- 数据库迁移版本以 `parking-boot/src/main/resources/db/migration/` 下 Flyway 脚本为准。
- 共享契约版本以 `docs/共享契约/` 为准。
