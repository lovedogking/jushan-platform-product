## 三、API 调用模式

```typescript
// 1. 定义类型（api/xxx-types.ts 或同文件中）
interface VehicleVO {
  id: number
  plateNumber: string
  vehicleType: string
  // ...
}

// 2. 封装 API（api/vehicle.ts）
/** 查询车辆 */
export function queryVehicle(plateNumber: string): Promise<VehicleVO | null> {
  return request.get(`/v1/vehicles/query`, { params: { plateNumber } })
}

// 3. 在组件中使用
import { queryVehicle } from '@/api/vehicle'
const v = await queryVehicle('川A88888')
```

## 四、WebSocket 通信

```typescript
// stores/monitor.ts
import { useWebSocket } from '@/utils/websocket'

// 连接与订阅
const ws = useWebSocket('/ws/booth')

// 监听消息
ws.onMessage((data) => {
  if (data.type === 'space_update') {
    remainingSpaces.value = data.payload
  }
})
```

## 五、关键组件说明

### PlateTag.vue
根据车牌号自动判断颜色：绿牌（新能源，7-8位第三位为字母）、黄牌（尾字母或首字母）、黑牌、白牌、蓝牌。判断逻辑在 `detectPlateColor()` 中。

### ManualReleaseModal.vue
人工放行弹窗，640px 宽，左右布局。使用 `KeyboardEvent` 虚拟键盘输入车牌。`queryVehicleType()` 在车牌输入超过 6 位时自动调用后端匹配车辆类型。入场/出场表单通过 `v-if="formState.direction==='exit'"` 区分计费区域。

### ChargePanel.vue
出场收费面板，从 Props 接收 `ParkingSessionVO`，显示入场时间、时长、费用。确认收费调用模拟支付接口→开闸→关闭面板。

## 六、开发注意事项

- **金额**：后端返回分，前端显示时 `/100` 转为元
- **路径前缀**：所有 API 经 `request.ts` 自动加 `/api`
- **权限拦截**：`@RequirePermission` 由后端校验，前端暂无按钮级权限控制
- **ant-design-vue**：按需引入，避免全量引入增加打包体积
- **响应拦截**：Axios 拦截器自动处理 `R<T>` 包装，code=200 时返回 `data.data`，非 200 时弹 toast 提示
