# 11 — 关键接口清单

> 完整 API 速查，按模块分组。路径统一前缀 `/api/v1`（未标注则不加 v1 前缀的为 `/api` 直接路径）。

## 鉴权

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/auth/login` | 登录（返回 JWT Token） |
| POST | `/auth/logout` | 退出 |
| POST | `/auth/refresh` | 刷新 Token |
