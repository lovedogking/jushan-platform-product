## 四、完整部署流程

### 4.1 后端部署

```bash
# 1. 本地编译
cd /path/to/jushan-platform
mvn clean package -pl parking-boot -am -Dmaven.test.skip=true

# 2. 上传 JAR
scp -i docs/服务器/密钥对.pem \
  parking-boot/target/parking-boot-1.0.0-SNAPSHOT.jar \
  root@120.26.3.4:/opt/jushan/parking-boot/target/

# 3. 重建并重启容器
ssh -i docs/服务器/密钥对.pem root@120.26.3.4 \
  "cd /opt/jushan && docker compose -f docker-compose.prod.yml --env-file .env.production up -d --build backend"
```

### 4.2 前端部署

```bash
# 1. 本地构建
cd frontend
npx vite build

# 2. 上传
rsync -avz --delete \
  -e "ssh -i ../docs/服务器/密钥对.pem" \
  dist/ root@120.26.3.4:/opt/jushan/frontend/dist/

# Nginx 直接读取静态文件，无需重启
```

### 4.3 Device Access 部署

```bash
# 1. 本地编译
cd device-access
mvn clean package -Dmaven.test.skip=true

# 2. 上传 JAR
scp -i ../docs/服务器/密钥对.pem \
  device-access-starter/target/device-access-starter-0.1.0-SNAPSHOT.jar \
  root@120.26.3.4:/opt/jushan/device-access/device-access-starter/target/

# 3. 重启 DA
ssh -i docs/服务器/密钥对.pem root@120.26.3.4 \
  "cd /opt/jushan && bash restart-device-access.sh"
```

### 4.4 仅重启后端（不重建镜像）

```bash
ssh -i docs/服务器/密钥对.pem root@120.26.3.4 \
  "docker compose -f /opt/jushan/docker-compose.prod.yml --env-file /opt/jushan/.env.production restart backend"
```

## 八、Flyway 迁移修复

如果迁移执行失败（checksum 不匹配等）：

```sql
-- 查看失败的迁移
SELECT * FROM flyway_schema_history WHERE success = 0;

-- 修复 checksum（当 SQL 手动修改后）
UPDATE flyway_schema_history SET checksum = NULL WHERE version = 'V20260906015';

-- 修复后重启后端触发 redo
```
