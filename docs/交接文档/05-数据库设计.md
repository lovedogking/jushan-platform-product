## 三、多租户设计

### Tenant ID 的三种状态

| tenantId | 含义 | 查询行为 |
|---|---|---|
| `NULL` | 平台用户（super_admin/platform_operator）| 跳过租户过滤，可查所有数据 |
| `NULL` | 岗亭管理员（booth）| 跳过租户过滤 |
| `具体值` | 租户用户 | SQL 自动追加 `AND tenant_id = ?` |

### 表粒度

- **租户表**：`sys_vehicle`、`parking_lot`、`parking_session` 等 → 自动过滤
- **全局表**：`sys_permission`、`sys_config`、`device_vendor` 等 → `JushanTenantLineHandler.IGNORE_TABLES` 跳过

### Service 层安全写法

```java
Long tenantId = TenantContext.getTenantId();
// 平台用户 tenantId==null，跳过归属校验
if (tenantId != null && !tenantId.equals(entity.getTenantId())) {
    throw new BusinessException("无权操作该数据");
}
```

## 四、关键字段约定

| 约定 | 说明 |
|---|---|
| 金额 | 一律 `INT` / `BIGINT`，单位**分** |
| 软删除 | 通过 `deleted_at` 字段逻辑删除 |
| 时间 | 一律 `DATETIME`，存储 UTC，应用层转 Asia/Shanghai |
| 主键 | 雪花 ID（默认，`ASSIGN_ID`），但 Entity 需要 `@TableId(type = IdType.AUTO)`（DB 实际用自增） |
| 租户 | `tenant_id` BIGINT，业务表必含 |

## 五、常用查询示例

```sql
-- 查在场车辆
SELECT * FROM parking_session WHERE exit_time IS NULL;

-- 某车场的在场统计
SELECT COUNT(*) FROM parking_session ps
JOIN parking_lane pl ON ps.lane_id = pl.id
WHERE pl.parking_lot_id = ? AND ps.exit_time IS NULL;

-- 设备识别事件（最近20条）
SELECT * FROM recognition_event_log ORDER BY created_at DESC LIMIT 20;

-- 操作日志
SELECT * FROM gate_operation_log
WHERE parking_lot_id = ? ORDER BY created_at DESC LIMIT 50;

-- Flyway 状态
SELECT version, description, checksum, installed_on, success
FROM flyway_schema_history ORDER BY installed_on;
```
