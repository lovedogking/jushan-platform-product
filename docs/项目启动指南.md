# 智慧停车 SaaS 平台 — 项目启动指南

> 给接手项目的同事，从头搭建开发环境并启动所有服务。

---

## 一、前置环境要求

| 软件 | 版本要求 | 用途 |
| :--- | :--- | :--- |
| **JDK** | 21（推荐 Azul Zulu 或 Eclipse Temurin） | 运行后端 |
| **Maven** | 3.9+ | 构建后端 |
| **MySQL** | 8.0+ | 主数据库 |
| **Redis** | 7+ | 缓存 |
| **RabbitMQ** | 3.12+ | 消息队列 |
| **Node.js** | 20 LTS | 运行前端 |
| **pnpm** | 9+ | 前端包管理 |

> 可选：**EMQX**（MQTT Broker）—— 如果不连真实设备可跳过。

## 二、基础设施启动

### 2.1 数据库初始化

项目包含两个数据库：

```bash
# 停车系统数据库（77 张表）
mysql -u root -p --default-character-set=utf8mb4 < docs/db/init-parking-system.sql

# 设备接入数据库（4 张表）
mysql -u root -p --default-character-set=utf8mb4 < docs/db/init-device-access.sql
```

数据库默认配置：

| 项目 | 数据库名 | 用户名 | 密码 |
| :--- | :--- | :--- | :--- |
| 停车系统 | `jushan_platform` | root | root |
| 设备接入 | `device_access` | root | root |

### 2.2 中间件

建议先确保以下服务在本地运行：

```bash
# Redis
redis-server  # 默认端口 6379

# RabbitMQ
rabbitmq-server  # 默认端口 5672（控制台 15672，用户 guest/guest）
```

## 三、后端启动

### 3.1 停车系统（parking-boot，主服务）

**Step 1：编译**
```bash
cd jushan-platform
mvn clean compile -pl parking-boot -am -DskipTests
```

**Step 2：启动**

在 IDEA 中创建 Spring Boot Run Configuration：

| 配置项 | 值 |
| :--- | :--- |
| **Main class** | `com.jushan.boot.ParkingApplication` |
| **Module** | `parking-boot` |
| **Active profiles** | `local`（默认已激活，无需额外设置） |
| **Working directory** | `$MODULE_WORKING_DIR$` |
| **VM options** | `-Dspring.profiles.active=local` |

或直接用 Maven 命令行启动：

```bash
mvn spring-boot:run -pl parking-boot -am -Dspring-boot.run.profiles=local -DskipTests
```

启动成功后访问：
- 服务地址：`http://localhost:8080`
- Swagger 文档：`http://localhost:8080/swagger-ui.html`

> **注意**：首次启动时 Flyway 会自动执行 99 个数据库迁移脚本。如果之前已执行过 `init-parking-system.sql`，Flyway 会创建 `flyway_schema_history` 表并标记所有迁移为 `BASELINE` 或 `SUCCESS` 状态。

**如果启动报错：**

| 错误 | 排查 |
| :--- | :--- |
| MySQL 连不上 | 检查 MySQL 是否运行，`jushan_platform` 库是否存在 |
| Redis 连不上 | 注释掉 `application-local.yml` 中 Redis 配置段即可降级 |
| RabbitMQ 连不上 | 检查 RabbitMQ 是否运行，默认用户 `guest/guest` |
| Flyway 校验失败 | 检查 `flyway_schema_history` 表是否完整，或 `clean-disabled` 不允许 clean |

### 3.2 设备接入（device-access，独立服务）

**Step 1：在 IDEA Maven 面板导入 `device-access/pom.xml`（是独立 Maven 项目，不在根 pom 中）**

**Step 2：编译**
```bash
cd device-access
mvn clean compile -pl device-access-starter -am -DskipTests
```

**Step 3：启动**

在 IDEA 中创建 Spring Boot Run Configuration：

| 配置项 | 值 |
| :--- | :--- |
| **Main class** | `com.smartparking.deviceaccess.DeviceAccessApplication` |
| **Module** | `device-access-starter` |
| **Working directory** | `$MODULE_WORKING_DIR$` |
| **Environment variables** | （可选，见下方说明） |

**环境变量说明：**

| 环境变量 | 默认值 | 说明 |
| :--- | :--- | :--- |
| `MQTT_BROKER_URL` | `tcp://121.41.131.215:1883` | MQTT Broker 地址（远程 EMQX） |
| `MQTT_USERNAME` | `admin` | MQTT 用户名 |
| `MQTT_PASSWORD` | `admin123` | MQTT 密码 |
| `WEBHOOK_URL` | `http://localhost:8080/api/v1/device-webhook/events` | 事件回调地址（parking 服务） |

**如果没有真实设备**，device-access 启动后会显示 "MQTT connected successfully"，但发关闸指令会超时（设备不在线），这是正常现象。

## 四、前端启动（booth-web）

```bash
cd booth-web

# 安装依赖
pnpm install

# 启动开发服务器
pnpm dev
```

默认访问地址：`http://localhost:5173`

| :--- | :--- | :--- |
| 超级管理员 | （见数据库 `sys_user` 表初始数据） | 首次登录需改密 |

> 如果本地启动时微信登录不可用，`application-local.yml` 中已启用 `wx.mock-login: true`，可以使用 mock 模式登录。

## 六、启动顺序（重要）

建议按以下顺序启动：

```
1. MySQL        ─── Redis ─── RabbitMQ    （基础设施）
2. parking-boot                           （后端主服务，含 Flyway 迁移）
3. device-access                          （设备接入层，可选）
4. booth-web                              （前端）
```

**启动验证：**

| 服务 | 验证方式 |
| :--- | :--- |
| parking-boot | `curl http://localhost:8080/actuator/health` → 返回 `{"status":"UP"}` |
| device-access | `curl http://localhost:8082/actuator/health` → 返回 `{"status":"UP"}` |
| booth-web | 浏览器打开 `http://localhost:5173` → 显示登录页 |

## 七、常见问题

### Q: 不需要 RabbitMQ/Redis 能启动吗？
可以。RabbitMQ 连不上不影响启动（消息队列降级），Redis 连不上可以注释掉配置段。

### Q: 不需要 device-access 能启动吗？
可以。parking-boot 启动时不依赖 device-access，只是闸机操作和识别事件功能不可用。

### Q: 前端登录报错？
确保 parking-boot 已启动且可访问（`http://localhost:8080`），前端 `.env` 或 `vite.config.ts` 中代理配置指向正确。

### Q: Maven 编译报错？
- 确保 JDK 21 已配置 `JAVA_HOME`
- 尝试 `mvn clean compile -DskipTests`（跳过测试）
- 如果依赖下载慢，可配置阿里云 Maven 镜像

### Q: MySQL 初始化脚本执行报错？
- 使用 `--default-character-set=utf8mb4` 参数
- 确保 MySQL 8.0+ 版本
