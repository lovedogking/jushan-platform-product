> 文档状态：**ACTIVE**

> 最后更新：2026-07-14

---

## 1. 项目定位

智慧停车 SaaS 平台（jushan-platform）是停车业务的核心业务平台，负责多租户管理、停车场配置、设备台账、停车计费、支付、订单管理、月卡、优惠券等业务功能，并提供管理后台、岗亭端和微信小程序。

Device Access 是独立的外部服务，负责设备通信、协议适配和事件转换。双方通过共享契约协作。

---

## 2. 业务端组成

| 端 | 用途 | 技术形态 |
|---|---|---|
| admin-web | 平台总后台、客户运营端 | Vue 3 + Ant Design Vue |
| booth-web | 岗亭实时监控与人工兜底 | Vue 3 + Ant Design Vue |
| miniapp | 车主自助服务（绑定车牌、查费、缴费） | 原生微信小程序 |
| 后端服务 | 业务 API、设备调用、数据持久化 | Spring Boot 模块化单体 |

---

## 3. 当前阶段

M0（基线与冻结）→ M1+（工程骨架）。基础框架已搭建（多模块 Maven、Spring Boot 3、MyBatis-Plus、Sa-Token），业务模块正在逐步实现。

**当前不可形成真实停车主链路** —— Device Access v0.2 无开闸、无车牌识别事件、无 RabbitMQ 事件发布。

---

## 4. 第一阶段交付边界（已实现/部分实现）

- 多租户注册、审核、启停
- 员工账号、RBAC 权限、超级管理员代操作
- 停车场、车道、设备台账与状态查询
- 收费规则 CRUD、版本、切换审计
- 微信车主登录、车牌绑定
- Mock/人工识别事件 → 入场停车记录
- Device Access 校时、状态查询调用与审计
- **Device Access 事件推送（Webhook）对接文档已冻结设计**（待 V01～V04 真机验证后启用）
- **Device Access 设备控制接口（开闸/显示屏/语音）预留设计**（待 v1.0 冻结后实现）

**尚未实现**：计费引擎、停车订单、微信支付、出场匹配与放行、开闸调用、月卡、优惠券、经营看板。
