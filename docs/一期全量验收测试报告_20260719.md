## 五、发现的问题

### 5.1 ⚠️ 次要问题：前端常开/常关缺少二次确认弹窗

- **需求**：GB-04/05 要求"前端常开/常关操作需二次确认"
- **现状**：`monitor/index.vue` (L168, L175) 常开/常关按钮直接调用 `toggleLockGate`/`toggleCloseGate`，没有二次确认弹窗。
- **风险**：误触可能导致道闸状态异常。
- **建议**：增加 `a-modal` 或 `a-popconfirm` 二次确认。

### 5.2 ⚠️ 次要问题：营收卡片未显示「即将上线」占位

- **需求**：AC-22 要求"营收卡片显示『即将上线』"
- **现状**：`Analytics.vue` 第 40-48 行显示的是实收金额（实际数据），没有显示"即将上线"占位文字。
- **建议**：若一期营收未接入真实支付，建议在前端显示"即将上线"占位符，避免数据误解。

### 5.3 ℹ️ 废弃代码：admin-web 构建失败

- **现状**：`admin-web` 存在 8 个 TypeScript 编译错误，无法构建。
- **说明**：根据 AGENTS.md V1.3，统一使用 `booth-web` 作为单一 Web 应用，`admin-web` 已废弃。
- **建议**：从仓库中移除 `admin-web` 目录，避免混淆。
