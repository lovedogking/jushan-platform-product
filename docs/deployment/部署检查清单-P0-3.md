## 1. 配置检查

### 1.1 `pyun.mock=true` 生产环境配置 ✅
- 配置文件：`application.yml` 第 107 行，`pyun.mock: true`（全局强制开启，无 `dev`/`prod` 覆盖）
- `application-prod.yml` 中无 `pyun` 或 `mock-payment` 覆盖，继承通用配置
- 所有支付接口已替换为 `MockPaymentService`，无真实支付平台调用

### 1.2 生产 Profile 不包含 `dev` ✅
- `application.yml` 默认 `spring.profiles.active: local`
- `application-prod.yml` 纯生产配置，无 `dev` 相关设置
- 生产环境通过环境变量 `SPRING_PROFILES_ACTIVE=prod` 激活

### 1.3 生产环境必须通过环境变量注入的敏感配置 ⚠️
| 环境变量 | 用途 | 是否必填 |
|---|---|---|
| `DB_URL` | MySQL JDBC URL | 必填 |
| `DB_USERNAME` | 数据库用户名 | 必填 |
| `DB_PASSWORD` | 数据库密码 | 必填 |
| `REDIS_HOST` | Redis 主机 | 必填 |
| `REDIS_PASSWORD` | Redis 密码 | 推荐 |
| `JWT_SECRET` | JWT 签名密钥（≥32字符） | 强推荐 |
| `DEVICE_ACCESS_WEBHOOK_ALLOWED_IPS` | Webhook IP 白名单 | 强推荐 |
| `JUSHAN_DEVICE_ACCESS_BASE_URL` | Device Access 地址 | 必填 |

### 1.4 `device-access.webhook.allowed-ips` ⚠️
- 当前默认值 `*`（全线放行）
- **生产必须**通过环境变量 `DEVICE_ACCESS_WEBHOOK_ALLOWED_IPS` 设置为 Device Access 实际 IP

## 4. 账号与权限检查

### 4.1 超级管理员 ✅
- 默认账号：`super_admin`
- 默认密码通过初始化脚本设置（需确认生产环境已修改密码）
- 权限：全部（所有 `sys_role_permission`）

### 4.2 岗亭管理员 ✅
- 角色：`booth_operator`
- 授权车场通过 `employee_parking_lot` 关联表控制
- 岗亭端登录后通过 `GET /api/v1/booth/parking-lots` 返回授权列表

### 4.3 小程序用户
- 权限：通过 JWT 中 `userType=wx_user` 标识
- `miniapp:view` 权限已通过 `V20260804001` 迁移写入 `customer_admin` 角色
- **已知限制**：wx_user JWT 不携带 permissions 字段，`@RequirePermission("miniapp:view")` 的权限校验依赖于 `PermissionProvider` 的后备查询（需 `sys_admin_account_role` 关联），小程序用户无法通过该检查。这需要二期修复。
