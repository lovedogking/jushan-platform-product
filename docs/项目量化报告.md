## 一、项目整体构成

```
jushan-platform/
├── parking-common          （公共 DTO / 常量）
├── parking-framework       （框架层：工具类 / 注解 / 异常）
├── parking-infrastructure  （基础设施：MQ / Redis / OSS）
├── parking-system          （核心业务逻辑 — 占总量 63%）
├── parking-boot            （启动层：配置 / Flyway / Security）
├── booth-web               （统一 Web 前端：Vue 3 + Ant Design Vue）
└── device-access           （独立 Maven 项目：设备接入适配器）
    ├── device-access-common
    ├── device-access-mqtt
    ├── device-access-adapter
    ├── device-access-registry
    ├── device-access-api
    ├── device-access-event
    └── device-access-starter
```

**Maven 模块**: 根工程 + 5 个 parking 子模块 + 7 个 device-access 子模块 = **13 个模块**
