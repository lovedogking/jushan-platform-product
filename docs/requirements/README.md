## 三、下一步（当前重点）

1. **按 [`二期实施计划.md`](二期实施计划.md) 推进 P0**：FeeRule 计算补全 → 识别链路切换 → H5/P云 真实支付 → 旧 BillingRule 删除。
2. **需求侧**：产出《一期功能现状清单》并经人确认 → 再产出《二期需求规格文档》。产出后在本目录登记链接。
3. **开发侧关键决策已确定**（详见 [`docs/adr/0001-fee-rule-migration.md`](../adr/0001-fee-rule-migration.md)）：
   - 计费体系：迁移至 `FeeRule`，删除 `BillingRule`；
   - 支付路线：生产环境走 **P云 OpenAPI 纯支付**（后端下单 → 返回 `pay_url` → 前端跳转 → P云 HTTP 回调），模拟支付保留为 fallback；
   - 定时任务：采用 Spring Scheduler（不用 xxl-job）；
   - 断网本地开闸：纳入二期 P0 异常场景。
4. **文档同步**：每次代码结构改动同步更新 [`docs/code-index/`](../code-index/README.md)。
