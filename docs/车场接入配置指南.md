# 远程车场接入配置指南

> **版本**：V1.0 ｜ **最后更新**：2026-07-25
> **适用场景**：新停车场需要通过互联网远程接入本系统（相机识别 → 开闸 → 收费）

---

## 一、架构前提

所有相机通过互联网连接到服务器的 EMQX MQTT Broker 和 Nginx HTTP 服务。相机不需要本地服务器，只需要能上网。

```
相机(车场A) ──MQTT──→ 服务器 EMQX (:1883)
相机(车场A) ──HTTP──→ 服务器 Nginx (:80) /images/upload
浏览器(岗亭) ──HTTPS──→ 服务器 Nginx (:80)
```

---

## 二、服务器侧（本系统管理员操作）

### 2.1 网络准备

确保服务器防火墙对车场 IP 开放以下端口：

| 端口 | 协议 | 用途 |
|------|------|------|
| 1883 | TCP | MQTT（相机连接） |
| 80 | TCP | HTTP API + 前端 + 图片上传 |

> 阿里云安全组：入方向添加车场的公网 IP 或 `0.0.0.0/0`（如不固定）

### 2.2 EMQX 配置

EMQX Dashboard：`http://<服务器IP>:18083`（仅内网）

需确认：
- 匿名访问已开启（相机无需账号密码连 MQTT）
- 如车场使用固定 IP，建议在 EMQX 中为该 IP 创建专用认证

### 2.3 创建租户和停车场（本系统管理后台）

1. **系统管理 → 租户管理**：创建租户（如"XX停车场"）
2. **系统管理 → 账号管理**：为该租户创建管理员账号（角色选 `customer_admin`）
3. **车场信息 → 停车场管理**：选择该租户，创建停车场（填写名称、总车位数等）
4. **车场信息 → 车道管理**：创建车道（入口/出口/双向）
5. **车场信息 → 设备管理**：
   - 新增设备 → 选择厂商（臻识/芊熠）、型号 → 填写相机序列号 → 绑定对应车道
   - 设置识别方向（1=入口, 2=出口）
   - 切到「识别联动」Tab → 开启自动播报 → 填写语音/显示屏模板

## 三、相机侧（车场现场人员操作）

### 3.1 臻识 C5/C6H 相机

通过相机 Web 管理页面（默认 `http://<相机IP>`）配置：

| 配置项 | 值 | 说明 |
|--------|-----|------|
| **MQTT Broker 地址** | `tcp://<服务器IP>:1883` | 如 `tcp://120.26.3.4:1883` |
| MQTT 用户名/密码 | 留空 | EMQX 已开启匿名访问 |
| MQTT Client ID | 自动生成 | 通常填相机序列号 |
| **心跳间隔** | 30 秒 | |
| **FTP 上传** | 开启 | 用于上传抓拍图片 |
| FTP 服务器 | `<服务器IP>` | 如 `120.26.3.4` |
| FTP 端口 | 21 | |
| FTP 用户名 | `camera` | |
| FTP 密码 | `l3M38o2kDtJhXefi` | 见服务器配置手册 |
| FTP 上传路径 | `parking/` | |
| 被动模式 | 开启 | 端口范围 30000-30010 |

### 3.2 芊熠 Q3 相机

通过相机内置 Web 页面或 `config.ini` 配置：

| 配置项 | 值 | 说明 |
|--------|-----|------|
| **MQTT Broker 地址** | `tcp://<服务器IP>:1883` | |
| MQTT 用户名/密码 | 留空 | |
| **alonepush** | `0`（默认） | 图片通过 MQTT base64 直传，无需另配 HTTP 上传 |
| **注册主题** | `/serverAll` | 固定，相机开机自动注册 |
| 上行主题 | `aiot/plate/{sn}` | 默认，也可使用 `/qymqtt/{sn}/qymqttpost` |
| 下行主题 | `device/plate/{sn}` | 默认 |

> 芊熠 Q3 图片通过 MQTT 消息的 `full_pic`/`plate_pic` 字段以 base64 编码直传，由 device-access 自动解码落盘。不需要额外配置 FTP。

### 3.3 OLM-M1D LED 显示屏（如通过芊熠相机 RS485 连接）

显示屏通过芊熠相机的 RS485 口连接，不需要独立配置网络。相机自动透传 OLM-M1D 协议帧。

## 四、本系统需要配置的参数清单

### 4.1 设备管理后台（必填）

| 参数 | 配置位置 | 说明 |
|------|----------|------|
| 厂商 | 设备编辑 → 设备厂商 | 选择"臻识"或"芊熠" |
| 型号 | 设备编辑 → 设备型号 | 选择对应型号 |
| 相机序列号 | 设备编辑 → 相机序列号 | 必须与相机实际 SN **完全一致**（大小写敏感） |
| 识别方向 | 设备编辑 → 识别方向 | 1=入口, 2=出口 |
| 绑定车道 | 设备编辑 → 绑定车道 | 选择对应车道 |
| IP 地址 | 设备编辑 → IP 地址 | 相机内网 IP（用于运维，非必填） |

### 4.2 识别联动（可选，用于自动语音播报+显示）

| 参数 | 配置位置 | 说明 |
|------|----------|------|
| 自动播报开关 | 设备编辑 → 识别联动 → 自动播报 | 设为"开" |
| 允许通行语音 | 同上 | 如 `欢迎光临`（入口）/ `一路顺风`（出口） |
| 允许通行显示 | 同上 | 显示的文字，车牌自动加在前面 |
| 禁止通行语音 | 同上 | 如 `禁止通行`（入口）/ `请缴费后出场`（出口） |
| 禁止通行显示 | 同上 | 同上 |
| 待机显示文字 | 同上 | 识别联动结束后恢复的默认文字，如 `飓山智慧停车` |
| 显示停留秒数 | 同上 | 默认 5 秒，设 0 不自动恢复 |

### 4.3 车道控闸模式（如需要）

| 参数 | 配置位置 | 说明 |
|------|----------|------|
| 控闸模式 | 车道管理 → 控闸模式 | AUTO=正常起落, ALWAYS_OPEN=常开, ALWAYS_CLOSE=常关 |

## 五、验证清单

逐项确认以下功能正常：

- [ ] 相机能连上 MQTT（EMQX Dashboard 能看到客户端在线）
- [ ] 相机能上传图片（臻识 FTP / 芊熠 MQTT base64）
- [ ] 本系统设备管理能看到设备在线（绿色标签）
- [ ] 车辆经过时岗亭端能收到识别事件（车牌+图片）
- [ ] 手动开闸/关闸正常
- [ ] 手动抓拍正常
- [ ] （如配置）识别联动自动语音播报+显示屏正常
- [ ] 岗亭端收费出场流程正常

## 六、常见问题

### Q1: 设备显示离线
1. 确认相机 MQTT 已连接（EMQX Dashboard → Clients）
2. 确认相机序列号与系统录入完全一致（注意大小写：芊熠通常是小写）
3. 确认相机能正常访问服务器 1883 端口（`telnet <服务器IP> 1883`）

### Q2: 识别事件不显示图片
1. **臻识**：确认 FTP 服务正常（`systemctl status vsftpd`），检查磁盘空间
2. **芊熠**：确认相机 `alonepush=0`，图片随 MQTT result 消息 base64 直传

### Q3: 语音播报/显示屏不工作
1. 确认是芊熠相机（臻识走不同协议）
2. 确认相机的 RS485 口连接了 OLM-M1D LED 屏卡
3. 确认设备管理 → 识别联动 Tab 中已开启自动播报并填写了模板

### Q4: 出场不自动放行
1. 确认该车牌已在「车辆管理 → 白名单」中录入
2. 或通过岗亭端手动放行（入口写入场，出口写出场）
