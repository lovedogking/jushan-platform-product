#### 4.3.2 Device Access 当前能力（摘自 AGENTS.md §2.2）

**仅三个 HTTP 接口可用：**

1. `POST /api/v1/devices/{deviceSn}/gate/open` — 开闸
2. `POST /api/v1/devices/{deviceSn}/time/sync` — 校时
3. `GET /api/v1/devices/{deviceSn}/status` — 查询状态

**关键行为约束：**
- 开闸同步等待设备回复，最长约 10 秒
- 当前无 commandId 幂等，每次调用都可能触发真实动作
- 开闸禁止任何自动重试
- 超时/网络中断必须标记为 UNCERTAIN
- 当前未确认：车牌识别事件、RabbitMQ 事件、HMAC、图片上传、关闸等

#### 4.3.3 P0 禁止项（摘自 AGENTS.md §14）

```
1. 越权、跨租户或跨停车场访问未失败关闭
2. 平台直连厂商设备、解析厂商协议
3. 修改 Device Access 源码或绕过已确认接口
4. 将目标设计或未冻结契约当作当前真实能力
5. 直接信任前端租户 ID、停车场 ID 或设备 SN
6. 自动重试开闸，或把超时直接判定为未动作
7. 开闸无权限校验、数据范围校验或审计
8. 支付回调未验签、未校验身份金额、无幂等或使用浮点金额
9. 泄露密钥、证书、Token、完整签名、密码或敏感个人信息
10. 未经用户授权执行 commit、push、破坏性 Git 操作
```
