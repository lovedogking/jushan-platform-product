# 车场管理合并 & 运营数据页 — 设计文档

> 日期: 2026-07-19 | 状态: 待评审

---

## 一、概述

将当前散落的**车场管理（SA-01）、车道管理（SA-02）、设备管理（SA-03）**三个独立页面合并为一个统一的「车场管理」页面（`/admin/parking`），采用主从列表式布局，使管理员在一个视图中完成车场 → 车道 → 设备的层级配置。

同时新增**运营数据页**（`/operation/analytics`），为超管和租户管理员提供车流量统计与可视化图表，营收部分一期先占位。

---

## 三、车场管理合并页（`/admin/parking`）

### 3.1 布局

主从列表式：

```
┌──────────────────────────────────────────────────────────┐
│  AdminLayout（顶部导航 + 左侧菜单，菜单项「车场管理」）   │
├──────────────┬───────────────────────────────────────────┤
│  左侧 300px  │  右侧内容区                                │
│              │                                            │
│  ┌搜索框───┐│  ┌──────────────────────────────────────┐  │
│  │         ││  │ Tab: 基本信息 | 车道管理 | 设备管理  │  │
│  └─────────┘│  ├──────────────────────────────────────┤  │
│  ┌车场列表─┐│  │                                      │  │
│  │ 车场 A ✓││  │  （根据选中 Tab 渲染对应内容）       │  │
│  │ 车场 B  ││  │                                      │  │
│  │ 车场 C  ││  │                                      │  │
│  │         ││  │                                      │  │
│  └─────────┘│  └──────────────────────────────────────┘  │
│  [+ 新增车场]│                                            │
└──────────────┴──────────────────────────────────────────┘
```

- 左侧车场列表带搜索过滤
- 点击选中车场后，右侧显示该车场的三个 Tab
- 左侧底部「新增车场」按钮
- 未选中车场时右侧显示空状态提示

### 3.2 Tab 1：基本信息

- 展示选中车场的详细表单，字段可直接编辑：
  - 车场名称
  - 总车位数
  - 负责人姓名
  - 联系电话
  - 详细地址
  - 状态（ENABLED / DISABLED）
- 底部「保存」按钮
- 数据提交复用现有 `PUT /api/admin/parking-lots/{id}`

### 3.3 Tab 2：车道管理

- 该车场下的车道列表（a-table）
- 列：车道编号、车道名称、出入口类型、闸机模式、状态、操作
- 支持新增/编辑/删除车道
- API 复用现有 `/api/admin/lanes` 系列接口

**新增/编辑车道弹窗**（分步表单）：

| 步骤 | 内容 |
| :--- | :--- |
| 基本信息 | 车道名称、车道编号、出入口类型（入口/出口/双向）、闸机模式 |
| 设备配置 | 根据出入口类型动态展开（详见 3.4） |

### 3.4 Tab 3：设备管理

- 该车场下的所有设备列表
- 列：设备名称、设备类型（相机/闸机）、型号、序列号、绑定车道、在线状态、操作
- 支持新增/编辑/删除设备、绑定/解绑车道
- API 复用现有 `/api/admin/devices` 系列接口

**设备配置表单字段**（相机类型）：

| 字段 | 说明 |
| :--- | :--- |
| 设备名称 | 如「东门入口相机」 |
| 设备型号 | 下拉选择，如「臻识 C5」 |
| 相机序列号（deviceSn） | 厂商序列号，用于适配器绑定 |
| IP 地址 | 新增字段，相机网络地址 |
| 端口 | 新增字段，默认 80 |
| 子网掩码 | 新增字段 |
| 网关地址 | 新增字段 |
| 识别方向 | 入口 / 出口（由车道类型自动带入） |

**双向车道逻辑**：
- 当车道类型为「双向」时，同时在弹窗中展示「入口相机」和「出口相机」两组表单
- 每组表单字段同上，分别提交为两个 Device 记录

## 四、运营数据页（`/operation/analytics`）

### 4.1 路由与权限

| 项 | 值 |
| :--- | :--- |
| 路径 | `/operation/analytics` |
| 角色 | platform（超管）、tenant（租户管理员） |
| 菜单 | 车场运营区 → 运营数据 |

### 4.2 布局

```
┌──────────────────────────────────────────────────────────────┐
│  筛选栏                                                      │
│  ┌──────────┐ ┌─────────────────────────────────────────┐   │
│  │ 停车场下拉 │ │ [今日] [本月] [今年] 或 日期范围选择器   │   │
│  └──────────┘ └─────────────────────────────────────────┘   │
├──────────────────────────────────────────────────────────────┤
│  KPI 卡片行（6 个 stat card）                                │
│  入场总数 | 出场总数 | 当前在场 | 实收总额 🔒 | 临停营收 🔒 | 固定车营收 🔒  │
├──────────────────────────────────────────────────────────────┤
│  图表区                                                      │
│  ┌─────────────────────┐ ┌─────────────────────┐            │
│  │ 车流量趋势（折线图）  │ │ 入场方式分布（饼图）  │            │
│  └─────────────────────┘ └─────────────────────┘            │
├──────────────────────────────────────────────────────────────┤
│  通行记录明细表                                              │
└──────────────────────────────────────────────────────────────┘
```

### 4.3 KPI 卡片

| 卡片 | 数据来源 | 一期状态 |
| :--- | :--- | :--- |
| 入场总数 | `COUNT(*)` WHERE entry_time IN 时间范围 | ✅ 真实数据 |
| 出场总数 | `COUNT(*)` WHERE exit_time IN 时间范围 | ✅ 真实数据 |
| 当前在场 | `COUNT(*)` WHERE status = 'IN' | ✅ 真实数据 |
| 实收总额 | - | 🔒 即将上线 |
| 临停营收 | - | 🔒 即将上线 |
| 固定车营收 | - | 🔒 即将上线 |

### 4.4 图表

**车流量趋势（折线图）**：
- X 轴：今日=按小时、本月=按天、今年=按月
- 双折线：入场（蓝色）/ 出场（绿色）
- 使用 ECharts 或 AntV G2

**入场方式分布（环形饼图）**：
- 分类：`whitelist_auto` / `manual_open` / `always_open_period` / `manual_entry`
- 展示各触发方式的占比

### 4.5 后端 API

新增统计接口：

```
GET /api/v1/admin/analytics/overview
  参数:
    lotId    (必填，超管传 0 表示全部)
    period   (today / month / year / custom)
    startDate (period=custom 时必填)
    endDate   (period=custom 时必填)
  返回:
    {
      entryCount: 1234,
      exitCount: 1189,
      currentInCount: 45,
      entryTriggerStats: {
        whitelist_auto: 800,
        manual_open: 350,
        always_open_period: 0,
        manual_entry: 84
      },
      trendData: [
        { time: "2026-07-19 08:00", entry: 45, exit: 30 },
        ...
      ],
      revenue: null   // 一期占位
    }
```

### 4.6 角色行为差异

| 角色 | 停车场下拉 |
| :--- | :--- |
| 超管 | 可选择任意车场，或「全部」 |
| 租户管理员 | 仅展示被分配的车场，无「全部」选项 |

## 九、技术约束

- Chart 库：使用 ECharts（通过 vue-echarts 或直接引入），与现有 booth-web 技术栈一致
- 后端统计接口不新增表，直接 SQL 聚合 `parking_session`
- Device 网络字段全部可选（nullable），不影响现有设备记录
- 不修改构建脚本与 CI 配置
- 金额字段一期始终返回 null，前端显示「即将上线」
