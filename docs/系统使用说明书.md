# 停车 SaaS 平台 — 超级管理员操作手册

> 涵盖运营端所有功能。按实际页面操作顺序编写。

---

## 1. 登录

打开运营端（端口 3000），使用超管账号登录。

- 超管的 `level=1`，`tenant_id` 为空，可以跨租户访问所有数据
- 首次登录会强制修改密码

---

## 2. 租户管理

**路径**：侧边菜单 → 租户管理

每个客户（物业公司、商场等）对应一个租户。租户之间数据完全隔离。

### 创建租户

前置条件：需要 `tenant:create` 权限。

1. 点击「新增租户」
2. 填写企业名称、联系人、联系电话
3. 可选：设置车场上限、设备上限、账号上限
4. 保存后租户状态为「已启用」

创建租户时，系统会自动创建默认公司（集团），用于后续的组织架构管理。

---

## 3. 公司管理

**路径**：侧边菜单 → 组织架构

每个租户下可以有多个公司（集团）。租户下第一个公司由创建租户时自动生成。

### 创建公司

1. 先选择目标租户
2. 点击新增，填写公司名称、联系人等
3. 公司的 `tenant_id` 自动继承所属租户

---

## 4. 停车场管理

**路径**：侧边菜单 → 车场运营 → 停车场管理

### 创建停车场

1. 先在顶部选择目标公司（下拉框列出当前用户有权限的公司）
2. 点击「新增停车场」
3. 填写：
   - 停车场名称、地址、联系电话
   - 总车位数
   - 状态：默认启用
   - 免费出场时间（分钟）：入场后 N 分钟内免费
   - 数据保留天数、图片保留天数
4. 保存

**注意**：创建停车场后状态为「禁用」，须先配置通道和设备，再启用。

### 启用停车场

点击「启用」按钮，系统执行就绪检查：
- 是否配置了入口通道和出口通道
- 通道是否绑定了相机
- 相机是否设置了道闸执行器

阻塞项未通过则无法启用。

### 为岗亭管理员分配停车场

在停车场列表的操作列中，可以为岗亭管理员分配停车场。分配记录存入 `sys_admin_account_parking_lot` 表——岗亭管理员可以跨租户管理被分配的停车场。

---

## 5. 通道（车道）管理

**路径**：侧边菜单 → 车场运营 → 通道管理

通道是停车场的基础设施——入口车道和出口车道。

### 创建通道

1. 先在下拉框中选择目标停车场
2. 点击「新增通道」
3. 填写：
   - **通道编号**：停车场内唯一（如 A1、A2），用于标识车道
   - **通道名称**：如「东大门入口」
   - **通道类型**：入口 / 出口 / 双向
   - 入口相机 ID / 出口相机 ID（可选，后续绑定）
   - 潮汐模式、相机模式（仅双向通道可配）
4. 保存

### 通道列表

列表中显示：编号、名称、类型、相机模式、相机绑定状态、潮汐模式、状态。

- 已删除的通道不会出现在列表中（软删除）
- 编辑通道时，停车场不可更改
- 删除为软删除（设置 `deleted_at`），不会物理删除数据

---

## 6. 设备管理

**路径**：侧边菜单 → 设备管理

### 创建（注册）设备

1. 先在顶部选择目标停车场
2. 点击「新增设备」
3. 填写：
   - **设备名称**：如「入口相机 1」
   - **设备编码**：停车场内唯一
   - **设备序列号（SN）**：厂商提供的设备唯一标识，**必须与实际设备一致**
   - **设备类型**：相机（CAMERA）或道闸（GATE）
   - 识别方向（相机才有）：入场 / 出场
   - 主备角色（相机才有）：主相机 / 备相机
   - 厂商、型号
4. 保存

**重要**：设备序列号必须与 Device Access 中注册的 `device_id` 一致，否则设备无法上线。

### 绑定车道

1. 在设备列表找到目标设备，点击「绑定车道」
2. 选择目标车道
3. 确认绑定

设备绑定车道后，岗亭端监控才能通过该设备控制道闸。

### 执行相机

道闸设备需要指定一台相机作为「执行相机」。该相机收到识别事件后，触发道闸开/关。

### 设备控制

每个设备的操作列提供：
- **校时**：同步设备时钟
- **开闸 / 关闸**：远程控制道闸
- **显示屏**：向相机 LCD 屏下发文字（支持多行、字号、颜色）
- **语音播报**：通过相机喇叭播放语音
- **在线状态**：绿点=在线，红点=离线

设备控制通过 Device Access 适配器 → MQTT → 物理设备。需要设备在线才能执行。

---

## 7. 账号管理

**路径**：侧边菜单 → 账号管理

### 账号级别

| level | 角色 | 可见范围 |
|-------|------|---------|
| 1 | 超级管理员 | 全平台 |
| 2 | 租户管理员 | 本租户停车场 |
| 3 | 岗亭管理员 | 被分配的停车场（跨租户） |

### 创建账号

1. 点击「新增账号」
2. 填写用户名、真实姓名、手机号（可选）
3. 选择账号级别（1/2/3）
4. 选择所属租户和公司
5. 为 level=3 分配停车场
6. 选择角色（与权限关联）
7. 系统生成初始密码，创建成功后弹出显示

### 启用 / 禁用

列表中操作列提供「启用」「禁用」按钮。禁用后该账号无法登录。

**注意**：超管无法禁用自己的账号。

### 权限说明

账号的权限由角色决定。角色关联权限码（`sys_role_permission` 表）。岗亭管理员至少需要：
- `booth:operate` — 查看停车场列表、操作道闸
- `booth:monitor` — 监控快照
- `booth:view` — 在场车辆、交接班
- `gate:open` — 开闸
- `gate:manual` — 人工操作

---

## 8. 岗亭端登录与操作

### 登录

岗亭端（端口 3001）使用岗亭管理员账号登录。

### 选择停车场

登录后左侧显示该岗亭管理员被授权的停车场列表。仅显示「已启用」状态的停车场。

### 监控页面

选中停车场后，主区域显示：
- **车场概览**：剩余车位、在场车辆、总车位
- **通道卡片**（入口 / 出口 / 双向）：
  - 通道名称 + 方向标签
  - 相机在线状态（主/备）
  - 最近识别车牌号和事件时间
  - 操作按钮：开闸、关闸、常开、常关、修改收费
- **最近识别事件**：车牌号、事件类型（入场/出场）、时间
- **异常提醒**：车位满、设备离线等

### 开闸 / 关闸

点击卡片的「开闸」或「关闸」按钮，系统通过 Device Access 下发 MQTT 指令到设备。

### 常开 / 常关

- **常开**：锁定道闸保持开启——发送 `lockGate` 命令，道闸继电器强制吸合
- **常关**：解除常开，恢复常规模式

---

## 9. 设备上线状态说明

- **在线（绿点）**：设备通过 MQTT 发送心跳到 EMQX，Device Access 收到后标记 ONLINE
- **离线（红点）**：超过心跳间隔未收到心跳，标记 OFFLINE
- **点击查询**：手动查询设备状态

---

## 10. Mock 模式切换

当无物理设备连接时，可以切换到 Mock 模式进行 UI 功能测试：

编辑 `parking-boot/src/main/resources/application-local.yml`：
```yaml
jushan:
  device-access:
    mock:
      enabled: true    # true=Mock 返回成功; false=真实设备调用
```

Mock 模式下所有设备操作直接返回成功，不经过 Device Access 和 MQTT。切换后需重启主平台。
