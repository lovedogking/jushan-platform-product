## 1. 系统概述

飓山智慧停车是一套多租户停车 SaaS 平台，通过统一 Web 应用为不同角色提供三大工作区域：

| 工作区域 | 主要使用者 | 核心功能 |
| :--- | :--- | :--- |
| **平台管理区** | 超级管理员 | 账号管理、车场基础信息配置 |
| **车场运营区** | 超级管理员、租户管理员 | 运营数据分析、车场/车道/设备管理、固定车管理、通行记录查询 |
| **岗亭工作区** | 全角色 | 实时监控、手动开闸、常开/常关、人工放行、现场收费、无牌车处理 |

系统通过摄像头自动识别车牌，白名单车辆自动放行，非白名单车辆推送至岗亭由人工处理。

## 2. 登录与账号安全

### 2.1 登录

1. 打开浏览器访问系统地址（由管理员提供）
2. 输入**用户名**和**密码**
3. 点击「登录」按钮
4. 系统将根据您的角色自动跳转到对应工作区：
   - 超级管理员 → 平台管理区（账号管理页）
   - 租户管理员 → 车场运营区（运营数据页）
   - 岗亭管理员 → 岗亭工作区（实时监控页）

### 2.2 安全机制

| 机制 | 说明 |
| :--- | :--- |
| 登录锁定 | 连续 5 次输入错误密码，账号将被锁定 15 分钟 |
| 首次登录 | 首次登录需修改初始密码 |
| 会话管理 | 登录凭证存储在浏览器会话中，关闭页面即失效，每次打开需重新登录 |
| 自动跳转 | 已登录用户访问登录页将自动跳转到对应工作区 |

### 2.3 退出登录

点击页面右上角「退出」按钮即可安全退出。

## 3. 角色与权限说明

系统共有三种后台管理角色：

| 角色 | 可见范围 | 工作区域 | 创建方式 |
| :--- | :--- | :--- | :--- |
| **超级管理员** | 全平台 | 三区全可见 | 系统预设 |

| **岗亭管理员** | 被分配的车场（可跨租户） | 岗亭工作区 | 超管创建 |

| 车场管理（查看/编辑） | ✅ | ✅ | ❌ |
| 运营数据分析 | ✅（全部车场） | ✅（被分配车场） | ❌ |
| 固定车管理（增删改查+导入） | ✅ | ✅ | ❌ |
| 通行记录查询 | ✅（全部数据） | ✅（本租户数据） | ✅（本车场数据） |
| 岗亭监控面板 | ✅ | ✅ | ✅ |
| 手动开闸 / 关闸 | ✅ | ✅ | ✅ |
| 常开 / 常关控制 | ✅ | ✅ | ✅ |
| 人工放行 | ✅ | ✅ | ✅ |
| 现场收费 | ✅ | ✅ | ✅ |
| 费用减免 | ✅（需权限） | ✅（需权限） | ✅（需权限） |

## 5. 平台管理区

> 超级管理员专属区域。登录后默认进入。

### 5.1 账号管理

**路径**：左侧菜单 → 账号管理

账号管理用于创建和维护系统内的所有后台账号。

#### 5.1.1 查看账号列表

页面以表格形式展示所有账号，包含以下信息：

| 列 | 说明 |
| :--- | :--- |
| 用户名 | 登录用的账号名 |
| 姓名 | 真实姓名 |
| 角色 | 租户管理员 / 岗亭管理员 |
| 手机号 | 绑定的手机号 |
| 状态 | 启用 / 锁定 / 停用 |
| 创建时间 | 账号创建时间 |
| 最后登录 | 最近一次登录时间 |
| 操作 | 编辑 / 重置密码 / 删除 |

支持按**用户名/姓名**搜索和按**状态**筛选。

#### 5.1.2 新建账号

1. 点击右上角「新建账号」按钮
2. 填写以下信息：

| 字段 | 必填 | 说明 |
| :--- | :---: | :--- |
| 用户名 | ✅ | 登录账号名，创建后不可修改 |
| 初始密码 | ✅ | 至少 6 位，用户首次登录需修改 |
| 姓名 | ✅ | 真实姓名 |
| 手机号 | ❌ | 选填 |
| 邮箱 | ❌ | 选填 |
| 账号类型 | ✅ | 租户管理员 或 岗亭管理员 |
| 可管理停车场 | ✅ | 多选，至少选择一个车场 |
| 允许费用减免 | ❌ | 仅岗亭管理员可选，勾选后可在岗亭端进行费用减免 |

3. 点击「确定」完成创建

> **注意**：
> - 租户管理员仅能管理被分配的车场
> - 岗亭管理员不隶属特定租户，可跨租户分配车场

#### 5.1.3 编辑账号

1. 在账号列表中点击目标账号的「编辑」
2. 可修改姓名、手机号、邮箱、可管理停车场、状态
3. 用户名和账号类型不可修改
4. 可启用/停用账号

#### 5.1.4 重置密码

1. 点击目标账号的「重置密码」
2. 系统将生成新密码并在弹窗中显示
3. **请务必当场记录新密码**，关闭弹窗后不可再次查看

#### 5.1.5 删除账号

点击「删除」并确认后，账号将被永久删除。此操作不可恢复。

## 6. 车场运营区

> 超级管理员和租户管理员均可访问。登录后默认进入运营数据页。

### 6.1 运营数据

**路径**：左侧菜单 → 运营数据

运营数据页提供停车场的核心经营指标和可视化图表。

#### 6.1.1 筛选条件

| 筛选项 | 说明 |
| :--- | :--- |
| 停车场 | 超管可选全部车场，租户管理员仅可见被分配车场 |
| 时间范围 | 今日 / 本月 / 今年 / 自定义日期范围 |

#### 6.1.2 KPI 指标卡片

| 指标 | 说明 |
| :--- | :--- |
| 入场总数 | 选定时间范围内的入场车辆总数 |
| 出场总数 | 选定时间范围内的出场车辆总数 |
| 当前在场 | 当前仍在停车场内的车辆数 |
| 实收总额 | 选定时间范围内的实际收费总额（元） |
| 固定车营收 | 固定车相关的营收（元） |
| 其他营收 | 非固定车相关的营收（元，一期为占位） |

#### 6.1.3 图表

| 图表 | 说明 |
| :--- | :--- |
| **车流量趋势**（折线图） | 展示选定时间范围内的入场/出场车流量变化趋势 |
| **入场方式分布**（饼图） | 展示不同入场触发方式（白名单自动/人工放行等）的占比分布 |

### 6.2 运营概览（隐藏路由）

**路径**：直接访问 `/operation/dashboard`（不在菜单中显示）

运营概览提供系统级别的关键指标总览：

| 指标卡片 | 说明 |
| :--- | :--- |
| 车场总数 | 系统中所有停车场数量 |
| 车道总数 | 系统中所有车道数量 |
| 设备总数 | 系统中所有设备数量 |
| 在场车辆 | 当前所有车场内在场车辆总和 |
| 今日入场 | 当天入场总次数 |
| 今日出场 | 当天出场总次数 |

### 6.3 车场管理

**路径**：左侧菜单 → 车场管理 → 车场信息

车场管理采用**左侧列表 + 右侧详情**的布局。

#### 6.3.1 车场列表（左侧）

- 显示所有（或已分配）停车场
- 每条显示车场名称、启停状态、车位数、地址
- 支持关键词搜索
- 点击某车场查看详情
- 超管可见「新增车场」按钮

#### 6.3.2 新增车场（仅超管）

1. 点击左侧「新增车场」按钮
2. 填写：车场名称（必填）、总车位数、负责人姓名、联系电话、详细地址
3. 点击确定

#### 6.3.3 车场详情（右侧三个 Tab）

**Tab 1 — 基本信息**：

编辑车场的基础信息，包括名称、车位数、地址、联系方式等。租户管理员可查看和编辑，超管额外可删除车场。

**Tab 2 — 车道管理**：

管理该车场下的所有车道。

| 操作 | 说明 |
| :--- | :--- |
| 新增车道 | 设置车道名称、方向（入口/出口/混合）、配置设备 |
| 编辑车道 | 修改车道名称、方向、设备绑定 |
| 删除车道 | 删除不再使用的车道 |

车道方向说明：

| 方向 | 说明 |
| :--- | :--- |
| 入口（ENTRY） | 仅允许车辆进入 |
| 出口（EXIT） | 仅允许车辆驶出 |
| 混合（MIXED） | 双向通行 |

创建车道时可同时配置入口和出口相机设备。双向车道会同时展示入口和出口两组相机配置表单。

**Tab 3 — 设备管理**：

管理该车场下的所有硬件设备（相机、显示屏等）。

设备信息包含：

| 字段 | 说明 |
| :--- | :--- |
| 设备名称 | 自定义名称，如"东门入口相机" |
| 设备序列号 | 硬件唯一标识 |
| 设备类型 | 相机 / 显示屏等 |
| 安装方向 | 入口 / 出口 / 双向 |
| IP 地址 | 设备网络 IP |
| 端口 | 设备通信端口 |
| 子网掩码 | 网络配置 |
| 网关 | 网络配置 |
| 在线状态 | 在线 / 离线 |

支持新增、编辑、删除设备。

### 6.4 固定车管理

**路径**：左侧菜单 → 车场管理 → 固定车管理

固定车（白名单车辆）是系统自动放行的核心数据。

#### 6.4.1 查看固定车列表

- 页面以表格展示所有固定车记录
- 支持按**车场**筛选（租户管理员自动锁定为其所属车场）
- 支持按**车牌号**搜索

#### 6.4.2 添加固定车

1. 点击「添加车牌」按钮
2. 填写：

| 字段 | 必填 | 说明 |
| :--- | :---: | :--- |
| 车牌号 | ✅ | 如"川A88888"，最长 8 位 |
| 生效车场 | ✅ | 该车牌在哪个车场生效 |
| 到期日期 | ❌ | 不填则长期有效；到期后自动失效 |
| 备注 | ❌ | 选填，最多 255 字 |

3. 同一车场内车牌号不可重复

#### 6.4.3 删除固定车

点击目标记录「删除」并确认。

#### 6.4.4 Excel 批量导入

1. 点击「Excel 导入」按钮
2. 选择 `.xlsx` 格式文件（需按规定模板填写）
3. 系统自动校验格式和重复性
4. 导入完成后弹出结果面板：

| 信息 | 说明 |
| :--- | :--- |
| 总数 | 文件中总记录数 |
| 成功 | 成功导入条数 |
| 失败 | 导入失败条数 |
| 失败明细 | 逐条列出失败原因（格式错误/重复等） |

### 6.5 通行记录查询

**路径**：左侧菜单 → 记录查询 → 通行记录

查询所有车辆的通行（停车会话）记录。

| 会话状态 | 在场 / 已出场 / 异常 | 筛选会话状态 |

#### 6.5.2 记录列表

| 列 | 说明 |
| :--- | :--- |
| 车牌号 | 识别的车牌号 |
| 车场名称 | 所属停车场 |
| 车道名称 | 通过的车道 |

#### 6.5.3 入场触发方式说明

| 触发方式 | 颜色标识 | 说明 |

| 人工补录 | 橙色 | 通过人工补录接口手动录入的通行记录 |

#### 6.5.4 会话状态说明

| 状态 | 标识 | 说明 |
| :--- | :--- | :--- |
| 在场（IN） | 蓝色 | 车辆已入场，尚未出场 |
| 已出场（OUT） | 灰色 | 车辆已完成出场 |
| 异常（EXCEPTION） | 红色 | 会话异常（如超时未出场自动关闭） |

## 7. 岗亭工作区

> 超级管理员、租户管理员、岗亭管理员均可使用。岗亭管理员登录默认进入此页面。

### 7.1 实时监控面板

**路径**：左侧菜单 → 岗亭工作区

监控面板采用**三段式布局**：

```
┌────────────┬──────────────────────────────┐
│            │      视频预览区（预留）        │
│  车场列表   ├──────────────────────────────┤
│            │     Tab 操作面板              │
│            │  ┌──────────────────────┐     │
│            │  │ 通行监控 │ 车辆查询  │     │
│            │  ├──────────────────────┤     │
│            │  │  车位统计卡片         │     │
│            │  │  车道网格卡片         │     │
│            │  │  识别事件 / 异常列表  │     │
│            │  └──────────────────────┘     │
└────────────┴──────────────────────────────┘
```

#### 7.1.1 选择车场

- 左侧列表显示所有可管理的停车场
- 点击切换车场，系统自动加载该车场的车道、设备和事件数据
- 切换车场时会断开上个车场的 WebSocket 连接并建立新连接

#### 7.1.2 连接状态

页面顶部显示 WebSocket 连接状态：

| 状态 | 颜色 | 说明 |
| :--- | :--- | :--- |
| 已连接 | 绿色 | 实时数据正常推送 |
| 连接中 | 蓝色 | 正在建立连接 |
| 重连中 | 橙色 | 连接断开，正在尝试重连 |
| 已断开 | 灰色 | 连接失败 |

> 系统支持断线自动重连并恢复 WebSocket 订阅状态。

#### 7.1.3 网络状态与离线队列

顶栏显示网络状态指示器：

| 状态 | 说明 |
| :--- | :--- |
| 在线（绿色圆点） | 网络正常，实时数据正常推送 |
| 离线（橙色圆点） | 网络断开，数据暂存本地 |
| 同步中（旋转图标） | 恢复在线后正在同步离线期间的数据 |
| 待同步（数字徽标） | 显示离线期间积压的待同步操作数量 |

**离线队列机制**：当浏览器处于离线状态时，写操作（新增/修改/删除）会自动存入浏览器本地数据库（IndexedDB）。网络恢复后自动将积压数据同步到服务器，超过 24 小时的离线记录自动清理。

### 7.3 常开 / 常关控制

> 操作需二次确认，防止误操作。

#### 常开模式

当车道需要长时间保持开启（如高峰期、设备检修时）：

1. 点击「常开」按钮
2. 确认弹窗：**"确定设置常开？道闸将锁定保持抬杆状态"**
3. 点击确认后，道闸锁定常开
4. 页面顶部显示**绿色常驻状态条**：「车道 XX 处于常开模式 — 道闸已锁定，车辆可直接通行」
5. 白名单命中不重复下发开闸指令

**取消常开**：

1. 点击「取消常开」
2. 确认后道闸恢复正常起落

#### 常关模式

当车道需要完全关闭（如夜间、紧急情况）：

1. 点击「常关」按钮
2. 确认弹窗：**"确定设置常关？白名单车辆将不再自动开闸"**
3. 点击确认后，道闸关闭
4. 页面顶部显示**橙色常驻状态条**：「车道 XX 处于常关模式 — 白名单不会自动开闸，需人工放行」
5. 白名单车辆不会自动开闸，事件照常推送，手动开闸仍可用

**取消常关**：

1. 点击「取消常关」
2. 确认后道闸恢复正常起落

#### 状态持久化

| 场景 | 行为 |
| :--- | :--- |
| 系统重启 | 自动查询所有非 AUTO 模式车道，重新下发 lockGate / 关闸 |
| 设备重连 | 设备状态变为 ONLINE 时，按当前 gate_mode 重新同步 |

### 7.5 现场收费

当出口识别到车辆时，系统自动弹出收费面板（右侧抽屉）。

#### 收费流程

1. **出口事件触发** → 右侧滑出收费面板
2. **车辆信息展示**：
   - 车牌号（大字体突出，含车牌颜色标签）
   - 车辆类型（临时车 / 固定车 / 等）
   - 入场时间
   - 停车时长
   - 应收金额（红色高亮，支持分转元显示）
3. **选择支付方式**：
   - 现金（一期唯一支持的支付方式）
4. **确认收费**：岗亭人员实收现金后点击确认
5. **收费完成**：记录落库，开闸放行

#### 费用减免

具备费用减免权限的岗亭人员可进行费用减免：

1. 在收费面板点击「费用减免」
2. 输入减免金额和减免原因（必填）
3. 减免金额超过 500 元时需二次确认
4. 确认后系统更新应收金额

> 费用减免权限在超管创建岗亭管理员账号时勾选「允许费用减免」赋予。

#### 免费放行

无需收费的场景（如内部车辆、系统故障）：

1. 点击「免费放行」
2. 填写放行原因
3. 确认后直接开闸放行

#### 人工放行（收费失败补救）

当收费操作完成后闸机未正常开启时：

- 收费结果面板显示「人工放行」按钮（红色警示）
- 点击后强制下发开闸指令

#### 修改收费规则

点击车道卡片的「修改收费」按钮可临时调整当前车道的收费规则：

| 可调整参数 | 说明 |
| :--- | :--- |
| 规则名称 | 收费规则标识 |
| 免费分钟数 | 入场后免费停车时长 |
| 计费单位 | 最小计费时间单位（分钟） |
| 首段价格 | 第一时段的收费标准（元） |
| 续段价格 | 后续每单位时间的收费标准（元） |
| 日封顶 | 单日最高收费上限（元） |

## 8. 业务规则说明

### 8.1 白名单自动放行（一期唯一自动放行场景）

```
摄像头识别车牌 → 匹配白名单 → 命中 → 自动开闸 → 记录入场记录
                            → 未命中 → 不开闸 → 推送岗亭事件 → 等待人工处理
```

### 8.2 闸机三种模式对比

| 模式 | 白名单自动开闸 | 手动开闸 | 典型场景 |
| :--- | :---: | :---: | :--- |
| **自动（AUTO）** | ✅ | ✅ | 正常运行 |
| **常开（ALWAYS_OPEN）** | 不开（闸已开） | 不适用 | 高峰期、设备检修 |
| **常关（ALWAYS_CLOSE）** | ❌ | ✅ | 夜间关闭、紧急情况 |

### 8.3 重复识别去重

- 同一车道同一车牌 **30 秒内**重复识别不会创建新的停车会话
- 事件仍会推送并在岗亭端展示

### 8.4 超时会话自动关闭

- 每日凌晨系统自动关闭**超过 24 小时**仍未出场的会话
- 关闭后状态标记为「异常」，备注"超时未出场自动关闭"

### 8.5 设备离线判定

- 设备最后状态包距今超过 **120 秒**即判定离线

## 9. 常见问题

### Q1：忘记密码怎么办？

联系超级管理员在「账号管理」中重置密码，系统会生成新密码。请当场记录，关闭弹窗后不可再次查看。

### Q2：登录时提示"账号已锁定"？

连续 5 次密码错误会触发 15 分钟锁定。等待 15 分钟后重试，或联系超管重置密码。

### Q3：岗亭管理员能看到所有车场吗？

岗亭管理员只能看到超管创建账号时分配的停车场。可以在多个车场之间切换（如果被分配了多个）。

### Q4：常开模式下还需要人工操作吗？

常开模式下道闸保持抬杆，车辆直接通行，无需人工操作。但识别事件仍会正常推送显示。

### Q5：白名单车辆为什么没有自动开闸？

请检查：
1. 该车辆是否已添加到「固定车管理」中
2. 车牌号是否完全匹配（包括省份简称）
3. 固定车是否已到期
4. 当前车道是否处于常关模式（常关时白名单不自动开闸）

### Q6：如何添加固定车？

进入车场运营区 → 车场管理 → 固定车管理，点击「添加车牌」。也可通过 Excel 批量导入。

### Q7：监控面板显示离线怎么办？

1. 检查页面顶部连接状态是否为「已连接」
2. 点击「刷新设备」按钮
3. 如果持续离线，检查硬件设备是否正常供电和联网
4. 联系技术支持排查

### Q8：收费面板没有自动弹出？

出口识别事件会触发收费面板自动弹出。如果未弹出，可手动点击出口事件，选择「收费处理」。

### Q9：识别车牌有误怎么办？

点击识别事件，使用「校正车牌」功能手动更正。已校正的车牌会以紫色标签标识。

### Q10：系统的入场触发方式有哪些？

| 触发方式 | 何时产生 |
| :--- | :--- |
| 白名单自动 | 白名单车辆被识别后自动开闸 |
| 人工放行 | 岗亭人员在监控面板手动开闸 |
| 常开时段 | 车道处于常开模式时车辆通行 |
| 人工补录 | 通过人工补录接口手动录入 |
