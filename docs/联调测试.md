## 三、设备接入测试方案（臻识 C5H）

### 3.1 相机 MQTT 配置步骤

**前提**：相机与服务器在同一局域网，或相机可访问公网 EMQX 地址。

| 步骤 | 操作 | 配置值 |
|------|------|--------|
| 1 | 登录相机后台 | `http://192.168.1.100`（默认），用户名 `admin`，密码 `admin` |
| 2 | 高级设置 → 识别设置 | 图片分辨率：`1280×720`<br>车牌结果编码：`UTF8`<br>新能源黄绿车牌：输入为绿 |
| 3 | 高级设置 → 音视频 → 编码参数 | 主码流/子码流分辨率：最低值<br>图像质量：最流畅 |
| 4 | 高级设置 → 高级网络 → MQTT | 勾选「启用自定义 MQTT」<br>服务器地址：你的 EMQX 地址<br>端口：`1883`<br>用户名/密码：EMQX 认证凭证<br>心跳间隔：`5` 秒 |
| 5 | Topic 配置 | 勾选「topic 内容叠加设备 SN」<br>确保以下 topic 已勾选：<br>- 识别结果：`/device/{sn}/recognition`<br>- 心跳：`/device/{sn}/status`<br>- 命令接收：`/device/{sn}/command` |
| 6 | 图片上传配置 | 勾选「相机抓图（全景图）」<br>去掉「车牌特写」勾选<br>上传模式：按你的存储方案配置（如本地或 OSS） |
| 7 | 保存并重启 | 相机重启后检查 MQTT 连接状态 |

## 四、完整业务流程端到端测试

### 场景 A：月卡车辆无感通行
```
1. 相机识别车牌「京A12345」
   → MQTT 识别事件 → 适配器 → Webhook → 平台
2. 平台 EntryService 判断：vehicleType=MONTHLY，在有效期内
   → 生成 ParkingRecord（无订单）
   → HTTP REST 下发开闸 → 适配器 → MQTT gpio_out → 相机 → 道闸开启
3. 岗亭端 WebSocket 推送：「京A12345 月卡车辆自动放行」
4. 车辆入场，ParkingSession 创建，余位 -1
5. 车辆出场，相机识别「京A12345」
   → ExitService 判断：月卡有效期内
   → 无订单生成，直接开闸放行
   → ParkingSession 关闭，余位 +1
```

**验证 SQL**：
```sql
-- 验证无订单生成
SELECT * FROM parking_order WHERE plate_number = '京A12345' AND created_at > NOW() - INTERVAL 1 HOUR;
-- 预期：0 条记录

-- 验证通行记录
SELECT * FROM parking_record WHERE plate_number = '京A12345' AND created_at > NOW() - INTERVAL 1 HOUR;
-- 预期：2 条记录（入场 + 出场）

-- 验证操作日志
SELECT * FROM operation_log WHERE operation_type = 'GATE_OPEN' AND description LIKE '%京A12345%';
-- 预期：2 条记录（自动开闸）
```

### 场景 B：临停车辆缴费出场
```
1. 相机识别车牌「京H88888」（临停）
   → 生成预订单，开闸放行
   → ParkingSession 创建，余位 -1
2. 车辆停车 30 分钟
3. 出场识别「京H88888」
   → 匹配 ParkingSession，计算费用 5 元

### 场景 C：固定车位车辆自动放行
```
1. 运营端绑定：车位 A-001 → 京B67890（有效期 1 个月）

   → EntryService 检查 fixed_space_binding：有生效绑定
