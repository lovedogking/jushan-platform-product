## 三、恢复路径

解冻 fee_rule 体系需满足以下全部条件：

1. **计费引擎对接**：FeeCalculationService 完成与 ExitService / ParkingFeeService 的对接，替换 BillingEngine
2. **全量回归测试**：覆盖四种计费模式（按时/按次/阶梯/分时段） + 跨天模式 + 封顶逻辑
3. **数据迁移**：billing_rule → fee_rule 存量规则映射 + Flyway 迁移脚本
4. **前端切换**：收费规则页改回 fee-rule API，费用试算页恢复可用
5. **旧体系下线**：BillingEngine / BillingRuleService 标记 @Deprecated，不再维护

## 四、注意事项

- fee_rule 相关 Flyway 迁移（V20260729001 等）不得修改或删除
- fee_rule 表的测试数据可保留
- ParkingZoneController 的区域管理功能（非计费部分）本期可继续使用
- 任何新功能不得接入 fee_rule 计费链路
