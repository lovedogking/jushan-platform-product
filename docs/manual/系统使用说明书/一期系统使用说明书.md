# 停车 SaaS 平台 — 一期系统使用说明书

> 版本：V1.0  
> 日期：2026-07-15  
> 适用范围：一期 MVP 运营后台 + 岗亭端 + 车主小程序

---

## 1. 系统概述

### 1.1 什么是停车 SaaS 平台

停车 SaaS 平台是一套面向车场运营方的在线管理系统，帮助车场完成车辆识别入场、自动计费、在线收费、放行出场的完整闭环。系统由三个端组成：

| 端 | 使用者 | 入口 | 用途 |
|---|--------|------|------|
| 运营后台 | 超管/租户管理员/车场管理员 | `http://域名:3000` | 车场配置、收费规则、车辆登记、数据查询 |
| 岗亭端 | 岗亭操作员 | `http://域名:3001` | 实时监控、收费放行、交接班 |
| 车主小程序 | 车主 | 微信内扫码 | 绑定车牌、缴费、月卡续费 |

### 1.2 一期能做什么

- ☑ 超级管理员统一创建租户和管理员账号并发放给客户
- ☑ 三级管理员权限体系，不同角色看不同数据
- ☑ 创建公司/集团、停车场、区域、车道
- ☑ 配置收费规则（按时长/按次/分时段），计费引擎自动算费
- ☑ 登记六类车辆（免费车、月租车、储值车、VIP车、超级车牌、黑名单）
- ☑ 一位多车（一个车位绑定多个车牌）
- ☑ 车辆入场识别→自动判定类型→出场计费→支付→放行
- ☑ 岗亭实时监控大屏、人工放行、交接班记录
- ☑ 车主微信小程序：绑定车牌、停车缴费、月卡续费
- ☑ P云聚合支付（微信/支付宝扫码支付）
- ☑ 全量操作日志审计

### 1.3 一期暂不支持

| 功能 | 预计上线 |
|------|----------|
| 心跳自动化监控（全自动离线告警） | 二期优化 |
| 充电优惠 | 二期 |
| 电子发票 | 二期 |
| 多级审批流 | 二期 |
| 蓝牙/NFC 盒子车牌 | 二期 |

## 2. 管理员体系

### 2.1 三级角色

```
超级管理员（一级）
  └── 管理所有租户，审核新租户，查看全局数据
        │
租户管理员（二级）
  └── 管理本公司/集团的停车场、收费规则、车辆、下级账号
        │
车场管理员（三级）
  └── 管理单个停车场的日常运营、车辆登记、收费放行
```

### 2.2 谁可以做什么

| 操作 | 超级管理员 | 租户管理员 | 车场管理员 |
|------|:---:|:---:|:---:|
| 创建租户并发放账号 | ✅ | — | — |
| 直接操作任意租户数据 | ✅ | — | — |
| 创建/编辑停车场 | ✅ | ✅（仅本租户） | — |
| 配置收费规则 | ✅ | ✅（仅本租户） | — |
| 登记车辆 | ✅ | ✅ | ✅（仅本车场） |
| 批量删除车辆 | ✅ | ✅ | — |
| 创建下级账号 | ✅ | ✅ | — |
| 监控大屏 | — | ✅ | ✅ |
| 人工放行 | — | ✅（本租户） | ✅（本车场） |
| 查看报表 | ✅ | ✅（仅本租户） | ✅（仅本车场） |

### 2.3 租户开通流程

```
超管登录后台 → 创建租户 → 创建租户管理员账号 → 发放账号给客户
```

> 租户不可自助注册，所有账号由超级管理员统一创建和管理。

## 3. 快速上手指南

### 3.1 超级管理员 — 开通新租户

**步骤 1：登录**

使用系统预置账号登录运营后台。

**步骤 2：审核租户**

1. 左侧菜单 → 「租户管理」
2. 查看待审核列表，点击某条记录查看详情
3. 核实企业信息后，点击「审核通过」
4. 系统自动将注册账号升级为租户管理员

**步骤 3：租户管理**

1. 超级管理员可直接进入任意租户的数据进行管理
2. 无需代操作模式，所有操作自动记录审计日志

---

### 3.2 租户管理员 — 搭建第一个车场

以下是从零搭建一个车场的完整流程，按顺序操作即可。

#### 第 1 步：创建公司

1. 左侧菜单 → 「系统配置」→ 「公司管理」
2. 点击「新增」：
   - 公司名称：如"XX商业管理有限公司"
   - 公司级别：选择「一级（集团）」
   - 其余信息按需填写
3. 如有子公司/分公司，选中集团后点击「新增下级」创建

#### 第 2 步：创建停车场

1. 左侧菜单 → 「车场管理」→ 「停车场列表」
2. 点击「新增停车场」：
   - 车场名称：如"XX商场地下停车场"
   - 所属公司：选择刚才创建的公司
   - 省市区域、详细地址、经纬度（可地图选点）
   - 总车位数：先填一个数字，后续由区域自动汇总
   - 状态：选择「营业中」
3. 保存后，停车场创建成功

#### 第 3 步：创建区域

1. 进入停车场详情 → 「区域管理」
2. 点击「新增区域」：
   - 区域名称：如"B1层普通区"、"B2 VIP区"
   - 区域标签：普通区 / VIP区 / 员工区等
   - 车位总数：该区域的物理车位数
   - 固定车位数：预留给月租车的车位数
   - 临停车位数 = 车位总数 − 固定车位数（自动计算）
3. 如果有多个区域，重复以上步骤

#### 第 4 步：创建车道

1. 停车场详情 → 「车道管理」
2. 点击「新增车道」：
   - 车道编号：如"A1"、"B2"
   - 车道名称：如"东门入口"、"西门出口"
   - 车道类型：入口 / 出口 / 双向
   - 所属区域：选择对应的区域
   - 绑定设备：在设备台账创建后再回来绑定

> **双向车道说明**：一个物理出入口同时支持入场和出场时，选"双向"。系统会为该车道创建入口侧和出口侧两个逻辑通道。

#### 第 5 步：配置收费规则

1. 左侧菜单 → 「收费管理」→ 「收费规则」
2. 点击「新增规则」：
   - 规则名称：如"商场标准收费"
   - 适用车场：选择刚才创建的车场
   - 适用区域：选择区域（不选则适用全部区域）
   - 计费模式：按时计费
3. 填写计费参数（以按时计费为例）：

| 参数 | 示例值 | 含义 |
|------|--------|------|
| 免费时长 | 15 分钟 | 15分钟内出场不收费 |
| 计费单位 | 30 分钟 | 按每30分钟为一个计费段 |
| 首时段价格 | 5 元 | 第一个计费段收5元 |
| 后续单价 | 2 元 | 之后每30分钟收2元 |
| 24 小时封顶 | 50 元 | 一天最多收50元 |

4. 保存后，点击「设为生效版本」使规则生效

> 系统支持按时计费、按次计费、分时段计费三种模式，详见 [7. 收费管理](#7-收费管理)。

#### 第 6 步：登记车辆

1. 左侧菜单 → 「车辆管理」→ 「车辆登记」
2. 选择要登记的类型（免费车/月租车/储值车等）
3. 点击「添加车牌」：

**月租车示例**：
- 车牌号码：`京A12345`
- 人员姓名：张三
- 手机号码：138xxxx1234
- 车位名称：A-001
- 收费标准：选择对应的月租收费标准
- 计费周期：按月
- 开始日期：2026-07-15
- 结束日期：自动计算

4. 保存后，该车辆即享受月租车待遇（有效期内无限次进出）

#### 第 7 步：配置进出策略（可选）

1. 左侧菜单 → 「车场管理」→ 「进出策略」
2. 以下场景均有默认策略，可按需修改：

| 场景 | 默认策略 | 可选策略 |
|------|----------|----------|
| 月卡过期入场 | 变为临时车 | 拒绝/弹窗确认/不开闸 |
| 重复入场（场内已有车） | 更新入场时间 | 拒绝/弹窗确认/新增记录 |
| 无入场记录出场 | 按计费规则收费 | 免费/拒绝/弹窗确认 |
| 车位已满 | 允许全部入场 | 禁止入场/部分车辆可入 |

#### 第 8 步：创建下级管理员

1. 左侧菜单 → 「系统配置」→ 「账号管理」
2. 点击「新增账号」：
   - 账号名称：如 `parking_admin_01`
   - 姓名：李四
   - 级别：选择「三级（车场管理员）」
   - 所属公司/车场：选择对应的停车场
   - 角色：分配对应角色
   - 系统生成初始密码

3. 将账号密码交给车场管理员，提示首次登录后修改密码

### 3.3 车场管理员 — 日常运营

#### 第 1 步：登录岗亭端

1. 打开岗亭端地址 `http://域名:3001`
2. 使用租户管理员分配的账号密码登录
3. 登录后看到实时监控大屏

#### 第 2 步：监控大屏

监控大屏实时展示：

- **车道状态**：各车道"空闲/占用/故障"及最近识别的车牌和抓拍图
- **在场信息**：当前在场车辆数 / 剩余车位数 / 今日入场/出场数
- **最近事件**：最近 10 条识别事件（车牌、时间、车道）
- **异常告警**：设备离线、黑名单车辆、无入场记录出场等

#### 第 3 步：处理出场收费

1. 车辆驶到出口，摄像头识别车牌
2. 系统自动匹配入场记录，计算停车费用
3. 岗亭屏幕弹出收费面板：
   - 显示车牌、入场时间、停车时长、应收金额
   - 操作员确认无误后，告诉车主金额
4. 车主出示微信/支付宝付款码
5. 操作员用扫码枪扫描 → 系统自动扣款
6. 扣款成功后，系统自动调用 Device Access 开闸指令，道闸抬起放行
7. 若开闸失败（如设备离线），屏幕显示告警，操作员可点击「人工放行」兜底

> 一期开闸通过 Device Access v0.4 HTTP API 调用实现。开闸结果分三层：命令已发送 → 设备回复成功 → 闸杆实际抬起。系统记录每层状态，若中间层失败，自动创建异常告警。

#### 第 4 步：人工放行（异常场景）

以下情况可能需要人工放行：

| 场景 | 操作 |
|------|------|
| 收费异常（设备故障） | 核实费用后手动填写金额收费 → 人工放行 |
| VIP 车辆 | 确认车牌后直接点击「免费放行」 |
| 紧急车辆（警车/消防） | 直接点击「免费放行」，选原因"紧急车辆" |

> ⚠️ 每次人工放行均记录操作人、时间、车牌、原因，请如实选择放行原因。

#### 第 5 步：交接班

1. 上班时：点击「接班」→ 输入接班时现金余额
2. 下班时：点击「交班」→ 核对接班以来系统自动统计的收款金额
3. 确认无误后提交，系统记录交班信息

### 3.4 车主 — 使用小程序

#### 第 1 步：微信登录与绑定车牌

1. 微信扫码进入车主小程序
2. 授权微信登录
3. 进入「我的」→「车牌管理」→ 添加车牌
4. 输入车牌号、选择颜色 → 保存
5. 可绑定多个车牌，设置一个为默认

#### 第 2 步：停车缴费

1. 离场前打开小程序
2. 首页显示当前停车状态（如在场）
3. 点击「去缴费」→ 查看停车费用明细
4. 选择支付方式（微信支付）
5. 点击「确认支付」→ 完成支付
6. 在出口处自动识别车牌，系统检测已支付后自动放行

#### 第 3 步：月卡续费

1. 进入「我的」→「月卡管理」
2. 查看月卡到期时间、续费金额
3. 点击「续费」→ 选择续费月数 → 支付
4. 续费成功后月卡有效期自动延长

## 4. 功能模块详解

### 4.1 公司/集团管理

**入口**：运营后台 → 系统配置 → 公司管理

支持三级组织架构：

```
集团（一级公司）
├── 子公司 A（二级）
│   └── 分公司 A-1（三级）
└── 子公司 B（二级）
```

**操作**：

- 新增公司：填写名称、选择级别，选择上级公司形成层级关系
- 编辑/删除：删除前检查无关联车场和子节点
- 新增下级：在某个公司下直接创建子公司

**与停车场的关系**：

- 一个停车场必须属于一个公司
- 一个公司下可有多个停车场
- 创建停车场时从公司树中选择

---

### 4.2 停车场管理

**入口**：运营后台 → 车场管理 → 停车场列表

#### 停车场基本信息

| 字段 | 说明 |
|------|------|
| 车场名称 | 如"XX商场地下停车场" |
| 所属公司 | 从公司树选择 |
| 区域类型 | 商场/写字楼/住宅小区/医院/景区/交通枢纽 |
| 省市区域 | 级联选择，支持地图选点自动填充 |
| 总车位数 | 由各区域自动汇总，不可手动修改 |
| 营业时间 | 如 00:00-24:00 全天 |
| 车场状态 | 营业中 / 暂停营业 / 装修升级 |

#### 区域管理

区域是对停车场内部的空间划分，一个区域可有独立的收费标准和管控策略。

| 字段 | 说明 |
|------|------|
| 区域名称 | 如"B1层普通区" |
| 区域标签 | 普通区 / VIP区 / 员工区 / 装卸货区 / 充电区 |
| 收费标准 | 绑定收费规则（不绑则继承车场规则） |
| 车位总数 | 该区域的物理车位数量 |
| 固定车位数 | 月租车专属，≤ 车位总数 |
| 临停车位数 | 自动计算 = 车位总数 − 固定车位数 |

#### 车道管理

| 字段 | 说明 |
|------|------|
| 车道编号 | 如"01"、"A1" |
| 车道名称 | 如"东门入口" |
| 车道类型 | 入口 / 出口 / 双向 |
| 所属区域 | 绑定区域 |
| 绑定设备 | 绑定相机/道闸设备 |

---

### 4.3 车位管控策略

**入口**：运营后台 → 车场管理 → 车位管控

#### 车位已满处理

| 策略 | 说明 |
|------|------|
| 可全部入场 | 不限制（默认） |
| 禁止入场 | 车位满后所有车辆不得入场 |
| 部分车辆可入场 | 设置白名单车辆类型（如月租车、VIP车可入） |

#### 余位计算

| 模式 | 公式 |
|------|------|
| 精准余位 | 总车位 − 当前在场车辆数 |
| 冗余余位 | 总车位 − 当前在场车辆数 − 缓冲数 |

> 冗余模式用于预留一定余量，避免车位信息延迟导致的实际满位。

---

### 4.4 车辆类型与登记

**入口**：运营后台 → 车辆管理 → 车辆登记

#### 六种车辆类型

| 类型 | 代码 | 计费方式 | 典型场景 |
|------|------|----------|----------|
| **免费车** | FREE | 不收费，记录进出 | 内部员工、合作单位 |
| **月租车** | MONTHLY | 包月/包年，有效期内无限次 | 长期租户 |
| **储值车** | PREPAID | 预充值，按次/按时扣余额 | 高频访客 |
| **VIP 车** | VIP | 不收费或特殊优惠，不受车位满限制 | 重要客户 |
| **超级车牌** | SUPER | 绕过大部分系统限制（不收费/不限行） | 测试/应急 |
| **黑名单** | BLACKLIST | 禁止入场 | 欠费/违规车辆 |

#### 一位多车

一个车位或一个月卡可以绑定多个车牌（默认最多 2 个，管理员可配置 1-10 个）。

**规则**：同一时间只有一辆车享受固定车待遇。

**示例**：
- 业主 A 的车位绑定"京A12345"和"京B67890"
- 京A12345 先入场→享受月租待遇
- 京B67890 后入场→按临时车计费
- 京A12345 出场后→京B67890 自动升级为月租待遇

#### 车辆类型判定优先级

入场时系统自动按以下顺序判定车辆类型：

```
黑名单 → 超级车牌 → VIP → 月租车（含过期检查） → 储值车 → 免费车 → 临时车
```

### 4.5 进出策略

**入口**：运营后台 → 车场管理 → 进出策略

#### 入场策略（关键场景）

| 场景 | 默认 | 可选 |
|------|------|------|
| 月卡过期入场 | 变临时车 | 拒绝/弹窗确认 |
| 场内已有此车牌 | 更新入场时间 | 拒绝/弹窗/新增记录 |
| 固定车位过期入场 | 变临时车 | 拒绝/弹窗确认 |

#### 出场策略（关键场景）

| 场景 | 默认 | 可选 |
|------|------|------|
| 无入场记录出场 | 按计费规则收费 | 免费/拒绝/弹窗确认 |
| 月卡过期出场 | 按临时车补费 | 自动出场/不开闸 |
| 过期 N 天后仍有效 | 3 天宽限期 | 可配置天数 |

#### 重复入场处理

同一车牌同一停车场已有在场记录时：

| 策略 | 行为 |
|------|------|
| REJECT | 拒绝入场，记录异常 |
| UPDATE | 更新原记录入场时间和抓拍图（默认） |
| EXCEPTION | 原记录标记异常，创建新记录 |

### 4.7 收费管理

**入口**：运营后台 → 收费管理 → 收费规则

#### 三种计费模式

**按时计费**：

| 参数 | 说明 | 示例 |
|------|------|------|
| 免费时长 | 超时才开始计费 | 15 分钟 |
| 计费单位 | 最小计费时间段 | 30 分钟 |
| 首时段价格 | 第一个计费段价格 | 5 元 |
| 后续单价 | 之后每个计费段价格 | 2 元/30 分钟 |
| 24h 封顶 | 单日最高收费 | 50 元 |
| 夜间封顶 | 夜间时段单独封顶 | 20 元 |

**按次计费**：

- 固定金额：每车每次 10 元
- 当日封顶：同车单日最多计费 N 次

**分时段计费**：

| 时段 | 时间 | 单价 | 封顶 |
|------|------|------|------|
| 白天 | 08:00-22:00 | 2 元/30分钟 | 50 元 |
| 夜间 | 22:00-08:00 | 1 元/60分钟 | 20 元 |

#### 规则优先级

```
区域特殊规则 > 车场通用规则 > 平台默认规则
```

#### 规则版本管理

- 修改规则后不会立即影响正在计费的车辆
- 通过「设为生效版本」切换，切换记录可追溯
- 历史版本保留只读

#### 费用试算

在收费规则页面可输入停留时长，试算对应费用，方便调试。

### 4.8 支付管理

**入口**：运营后台 → 支付管理（超管/租户管理员）

#### 商户配置

每个停车场绑定一个 P云商户号（进件后由 P云分配）。

| 配置项 | 说明 |
|--------|------|
| P云应用ID | 平台分配 |
| P云商户号 | 车场进件后分配 |
| 车场UUID | 车场唯一标识 |
| 应用密钥 | 加密存储 |

#### 三种支付场景

**岗亭被扫**（最常见）：
```
车辆出场 → 系统计费 → 操作员扫描车主付款码 → P云扣款 → 放行
```

**小程序主动支付**：
```
车主打开小程序 → 查询停车费 → 确认支付 → 微信支付 → 系统收到回调 → 出场自动放行
```

**无感支付**（需车主开通）：
```
车辆出场 → 系统自动发起扣款 → P云扣款 → 放行
```

#### 退款

1. 运营后台 → 订单管理 → 找到需退款的订单
2. 点击「退款」→ 确认退款金额（不可超过实付金额）
3. 提交 → 需租户管理员审批 → 审批通过 → 调用 P云原路退款

### 4.9 岗亭监控

**入口**：岗亭端 `http://域名:3001`

#### 监控大屏

左侧：车道实时状态列表
- 每个车道显示：编号、名称、最近识别车牌、状态灯

中部：在场车辆信息
- 当前在场数 / 总车位数 / 剩余车位数
- 今日入场/出场统计

右侧：最新识别事件
- 最近 10 条记录（车牌、车道、时间、抓拍图缩略图）

底部：异常告警条
- 滚动显示未处理的告警（设备离线、黑名单、余额不足等）

#### 人工放行操作

1. 在监控大屏点击需要放行的车辆
2. 进入放行确认页：
   - 核实车牌、入场时间、费用
   - 选择放行原因：收费完成 / 免费放行（VIP/紧急）
   - 点击「确认放行」
3. 放行操作记录到审计日志

#### 交接班

**接班**：
1. 点击顶部「接班」
2. 输入接班时现金余额
3. 确认 → 开始当班

**交班**：
1. 点击顶部「交班」
2. 系统自动统计本班：
   - 当班收款总额
   - 处理订单数
   - 人工放行次数
3. 填入交班时现金余额
4. 确认 → 结束当班，生成交班记录

### 5.1 车牌颜色说明

| 颜色 | 类型 | 特殊规则 |
|------|------|----------|
| 蓝牌 | 小型汽车 | 正常计费 |
| 黄牌 | 大型汽车 | 可配置是否允许办月卡 |

| 白牌 | 警车/军车/消防 | 自动放行，不计费 |
| 黑牌 | 领事馆/外籍 | 正常计费 |

### 5.2 常见问题

**Q：车牌识别不准确怎么办？**

岗亭操作员可在监控大屏手动修正车牌号，修正后的车牌用于匹配和计费。

**Q：车主缴费后未及时出场怎么办？**

系统设有"已支付宽限期"（默认 15 分钟），宽限期内出场不重复收费。超时后重新计算费用。

**Q：网络中断怎么办？**

岗亭端支持脱机模式。网络中断时，操作员可继续人工放行，系统本地缓存操作记录，网络恢复后自动同步到服务器。

**Q：如何查看某辆车的完整进出记录？**

运营后台 → 车辆管理 → 搜索车牌 → 点击进入车辆详情 → 查看进出记录 Tab。
