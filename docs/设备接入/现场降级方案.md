# 现场降级方案

> **版本**: V1.0 | **日期**: 2026-07-18 | **关联**: 任务包 7-1

## 1. PDNS 降级：DNS 不可用时 Adapter 连接 EMQX 回退方案

### 问题场景
EMQX Broker 通过域名暴露 MQTTS 服务（如 `emqx.your-domain.com:8883`），
当 DNS 服务不可用时，Adapter 无法解析域名，导致所有设备控制指令中断。

### 回退方案

**方案 A：静态 hosts 文件回退**

在 Adapter 服务器上配置 hosts 文件作为 DNS 降级：

```bash
# /etc/hosts
10.0.1.100  emqx.your-domain.com   # EMQX 内网静态 IP
```

部署脚本中通过 Ansible/Cloud-Init 预置此条目。

**方案 B：Adapter 配置双地址**

Adapter 代码中同时支持域名和 IP 地址配置，DNS 解析失败时自动回退到 IP：

```yaml
# Adapter 配置
mqtt:
  broker-host: emqx.your-domain.com
  broker-ip: 10.0.1.100    # DNS 不可用时回退
  broker-port: 8883
```

### 监控告警

在 Adapter 中增加 DNS 解析失败的 metrics 指标，推送到 Prometheus：
- `mqtt.dns.resolve.failures` — DNS 解析失败次数
- `mqtt.dns.fallback.activated` — 回退到静态 IP 时触发

## 2. 平台不可达：相机本地白名单同步

当平台 API 不可达时，Adapter/相机使用最后一次拉取的白名单快照进行自动放行判断。

白名单同步 API（任务包 7-1）：
```
GET /api/v1/internal/whitelist/sync?parkingLotId={lotId}
Authorization: Bearer <api-key>
```

Adapter 定时任务：
- 每 5 分钟拉取一次全量白名单
- 缓存最近 3 个快照（15 分钟内有效）
- 平台不可达时使用最近一次有效快照

## 3. PDNS 云平台备选通路（臻识 C5 SDK）

### 问题场景

当 Adapter 到平台之间的 HTTP 通道不可达时（如内网链路中断、平台 API 服务宕机），Adapter 无法下发开闸指令。此时相机仍可借助臻识 C5 SDK 的 PDNS（平台设备网络服务）通路独立完成车辆识别与放行决策。

### 回退方案

**方案：PDNS 平台备选通路（本期仅记录方案，不做对接）**

臻识 C5 系列相机的 SDK 提供 `ConvertPDNSNetworkParam` 接口，允许将网络参数转换为 PDNS 通信模式。当 Adapter 检测到与平台主通道的连通性丢失后，可执行以下流程：

1. **断连检测**：Adapter 通过心跳探测（HTTP GET `/health`）检测平台可用性。连续 3 次心跳失败（间隔 10 秒）判定为主通道不可达。
2. **激活 PDNS 通路**：调用 `ConvertPDNSNetworkParam` 将相机的网络参数切换为 PDNS 模式，使相机直接通过 PDNS 云平台上报识别事件和接收开闸指令。
3. **白名单同步至 PDNS**：在 PDNS 模式下，Adapter 将缓存的本地白名单快照推送至相机本地存储，保证月卡/固定车位/白名单车辆可正常自动放行。
4. **临停车辆处理**：PDNS 模式下计费引擎不可用，临停车按车场配置决定（放行并记录欠费 / 拦截等待人工处理）。
5. **主通道恢复**：Adapter 持续探测主通道，恢复后切换回 HTTP Webhook 模式，调用 PDNS 逆转换接口将相机切回标准模式。

### 状态机

```
  [主通道正常] ──心跳3次失败──→ [PDNS激活中] ──转换成功──→ [PDNS模式运行]
       │                            │                        │
       │                            └──转换失败──→ [告警+重试]  │
       │                                                      │
       └────主通道恢复──────────────────────────────────────────┘
```

### 适用场景

| 场景 | PDNS 模式行为 |
|------|-------------|
| 月卡/固定车位/白名单车辆 | 相机本地白名单匹配 → 自动放行 |
| 临停车入场 | 正常记录识别事件，入场放行 |
| 临停车出场 | 无计费引擎 → 按车场配置拦截或放行 |
| 计费 | 不可用，恢复后补算 |
| 支付 | 不可用，欠费记录 |

### 本期不做对接

- **PDNS SDK 集成代码**：臻识 C5 `ConvertPDNSNetworkParam` 的实际调用和参数配置
- **PDNS 模式切换自动化**：断连检测后自动切换的逻辑
- **PDNS 逆转换**：主通道恢复后切回标准模式的逻辑
- **PDNS 模式下计费补算**：恢复后的离线计费回补逻辑

以上均为二期范围，本方案仅记录技术可行性评估和整体架构。

### 依赖与前置条件

- 臻识 C5 相机已配置 PDNS 服务地址
- Adapter 具备心跳探测和白名单缓存能力
- 运维侧提供 PDNS 云平台账号及 API Key
