# 项目文档目录

本文档目录按功能分类，便于团队成员和 AI 助手快速定位。

## 目录结构

| 目录 | 内容 | 关键文件 |
|------|------|---------|
| `requirements/` | 需求规格说明书 | `停车SaaS系统需求规格说明书_v1.0.md` |
| `deployment/` | 部署运维文档 | `部署检查清单-P0-3.md` |
| `roadmap/` | 产品规划/二期需求 | `二期需求优先级-P0-P3.md` |
| `architecture/` | 技术架构文档 | `通信架构说明.md`, `设备控制配置.md` |
| `manual/` | 用户操作手册 | `系统使用说明书/` |
| `archive/` | 归档（历史过程文档，不活跃维护） | `ai-handover/02-gap-analysis.md` |

## 使用说明

- **新开发者/AI 助手**：先阅读 `requirements/` 下的需求文档，再阅读 `architecture/` 下的架构文档
- **部署上线**：参考 `deployment/` 下的检查清单
- **迭代规划**：参考 `roadmap/` 下的二期需求优先级
- **历史文档**：`archive/` 下的文档为开发过程归档，仅作参考，不保证与当前代码一致
