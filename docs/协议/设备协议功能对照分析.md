# 臻识 & 芊熠 设备协议功能对照分析

> 分析日期：2026-07-26 · 更新日期：2026-07-26
> 协议版本：臻识 HTTP v1.9.7 / MQTT v1.1.14 · 芊熠 Q3 MQTT 基线 260401
> 适用范围：飓山智慧停车平台

---

## 一、本系统当前已实现功能

| 功能模块 | 具体能力 | 对接方式 |
|---------|---------|---------|
| 识别结果接收 | 车牌号、车牌颜色、方向、全景大图 | MQTT webhook → `DeviceWebhookService` |
| 开闸 | IO脉冲开闸 | HTTP → `DeviceAccessClient.gateControl()` |
| 直接开闸 | 不指定IO口的简化开闸 | MQTT `gate_direct_open`（臻识 v1.1.14） |
| 语音播报 | 准入/禁入/放行 三种场景，支持 `{plate}` `{type}` 占位符 | HTTP → `DeviceService.voiceControl()` |
| 抓拍 | 开闸前触发抓拍获取全景图 | HTTP → `captureImage()` |
| 显示屏文本 | 欢迎语/禁入语模板下发，可配置文字内容 | HTTP → `DeviceWebhookService` 识别回复中带 |
| 设备注册/心跳 | MQTT 注册 + keep-alive | MQTT → `DeviceRegistry` |
| 计费引擎 | 按时/按次/免费/跨天计费 | 平台侧 |
| 车辆类型决策 | 月租/临时/VIP/免费，支持车牌颜色维度 | 平台侧 |
| 操作日志 | 每次开闸自动记录含抓拍图 | 平台侧 |
| 余位管理 | 直接设定剩余车位数 | 平台侧 |

## 四、下行控制（平台 → 设备）

### 4.1 道闸控制

| 能力 | 臻识 HTTP | 臻识 MQTT | 芊熠 MQTT | 本系统 | 计划 |
|------|:---:|:---:|:---:|:---:|------|
| **开闸（脉冲）** | `ivs_ioctrl` | `gpio_out` | `relay_control` | ✅ | — |
| **常开锁定** | `SetIoLockStatus` | `set_io_lock_status` | `open_gate_keep_open` | ❌ | **P0** |
| **关闸（解除常开）** | `SetIoLockStatus`(status=0) | `set_io_lock_status` | `close_gate` | ❌ | **P0** |
| 查询道闸状态 | — | `get_io_status` | `get_gate_status` | ❌ | **P0** |

> **设计决策**：控闸只需三种能力：**开闸（脉冲）/ 常开锁定 / 关闸（解除锁定）**。不需要「常关锁定」（道闸物理上常关是常态）。

### 4.2 语音播报

#### 当前支持的模板

| 模板 | 存储位置 | 支持占位符 | 触发场景 |
|------|---------|-----------|---------|
| 准入欢迎语 | `device.voice_welcome_template` | `{plate}` | 自动识别 + 白名单车辆入场 |
| 禁入提示语 | `device.voice_deny_template` | `{plate}` | 自动识别 + 非白名单/黑名单车辆 |
| 手动放行语 | `device.voice_release_template` | `{plate}`, `{type}` | 岗亭手动开闸/人工放行 |

> **配置入口**：设备管理 → 编辑设备 → 语音模板区（三个输入框）
> **不配置时默认**：准入="欢迎{plate}"，禁入="禁止通行"，放行="{plate},{type}"
> **臻识设备**：通过 HTTP comet 回复或 MQTT `tts_voice` 下发 base64 编码的 UTF-8 文字
> **芊熠设备**：暂未对接语音协议（后续同臻识方式）

#### 语音参数

| 参数 | 臻识 | 芊熠 | 本系统 | 计划 |
|------|:---:|:---:|:---:|------|
| 音量 (1-100) | ✅ | ❌ | ❌ | P1 |
| 男女声 | ✅ (0男/1女) | ❌ | ❌ | P1 |

### 4.5 白名单管理（关键功能）

| 能力 | 臻识 HTTP | 臻识 MQTT | 芊熠 MQTT | 本系统 | 计划 |
|------|:---:|:---:|:---:|:---:|------|
| 全量下发 | ✅ `white_list_operate`(add) | ✅ | ✅ | ❌ | **P0** |
| 增量添加 | ✅ | ✅ | ✅ | ❌ | **P0** |
| 单条删除 | ✅ | ✅ | ✅ | ❌ | **P0** |
| 清空全部 | ✅ | ✅ | ✅ | ❌ | **P0** |
| 时间段限制 | ✅ `enable_time`/`overdue_time` | ✅ `seg_time` | ❌ | ❌ | P1 |
| 黑名单标记 | ✅ `need_alarm=1` | ✅ | ❌ | ❌ | P2 |

> **核心逻辑**：平台侧管理的月卡车/VIP车/固定车，在下发车辆时同步推送白名单到设备。
> - 设备**在线时**：实时同步增量变更（增/删/改）
> - 设备**断网恢复时**：触发一次全量同步
> - 设备**脱机工作时**：本地白名单判定，自行开闸放行，记录缓存在设备中
> - **臻识**每次识别结果会携带 `gioouts[].ctrltype` 标识脱机白名单开闸，平台收到后补录

## 五、优先实现计划

### P0 — 下一迭代（核心能力补齐）

| 序号 | 功能 | 品牌 | 工作量 | 说明 |
|:---:|------|------|:---:|------|
| 1 | **白名单下发到设备** | 臻识+芊熠 | 3天 | 平台车辆增删改时实时同步；断网重连后全量同步；设备本地判定离线放行 |
| 2 | **道闸状态监控** | 臻识 | 1天 | 订阅道闸开到位/关到位推送，岗亭端显示道闸实时状态 |
| 3 | **常开/关闸命令** | 臻识+芊熠 | 0.5天 | 消防模式、维护模式使用 |
| 4 | **显示屏基础参数** | 臻识+芊熠 | 1天 | 文字颜色、方向翻转、亮度音量 |
| 5 | **设备时间同步** | 臻识+芊熠 | 0.5天 | 设备注册/定时同步 |
| 6 | **改进识别字段存储** | 臻识 | 0.5天 | bodyColor、carLogo、confidence 落库备用 |

### P1 — 体验增强

| 功能 | 说明 |
|------|------|
| 语音音量/男女声配置 | 在语音模板旁加参数 |
| 识别区远程配置(芊熠) | 目标：减少跑现场 |
| IO输入事件(地感触发) | 接入地感，精准触发抓拍 |
| 设备重启命令 | 远程运维 |

### P2 — 锦上添花

| 功能 | 说明 |
|------|------|
| 脱机记录补传 | 网络恢复后拉取离线期间识别记录 |
| 手动触发识别 | 特殊场景强制抓拍 |
| 黑名单报警 | 黑名单车辆触发时语音+UI告警 |

### 不做

| 功能 | 理由 |
|------|------|
| 车牌小图存储/展示 | 全景图已满足需求 |
| 视频对讲 | 非当前业务场景 |
| 人脸门禁 | 非停车场景 |
| RFID/地锁/QR码/云台 | 无硬件需求 |
| LCD 复杂布局(JSON) | 基础文字+颜色已够用 |
| OSS 云存 | 本地存储够用 |
| 固件远程升级 | 手动升级更安全 |
