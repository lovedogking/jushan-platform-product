## 四、关键代码路径追踪

### 4.1 白名单命中链路（确认生效）
```
DeviceWebhookService.processEvent()
  → DeviceWebhookEventHandler.handlePlateRecognized()
    → RecognitionEventServiceImpl.handleEvent(cmd)
      → vehicleTypeDecisionService.decide(plate, cmd.getParkingLotId(), tenantId)
        → VehicleTypeDecisionServiceImpl.isWhitelisted(parkingLotId, plate)
          → vehicleListService.isWhitelisted(parkingLotId, plate) → true
        → 返回 allowEntry=true, vehicleType=WHITE
      → handleEntry() → ParkingSessionService.entry()
        → entryTrigger = (gateMode==ALWAYS_OPEN ? always_open_period : whitelist_auto)
      → executeGateOpen() → DeviceAccessClient.openGate()
```
**确认**: `parkingLotId` 不再为 null，白名单检查能正确命中。

### 4.2 BR-08 去重链路
```
DeviceWebhookService.processEvent()
  → 车牌去重检查(plate:direction:laneId, 30s)
    → 命中: wsPublisher.sendLightweightRecognitionEvent() → /topic/booth/{lotId}/events
    → 未命中: 正常走 handlePlateRecognized → 创建会话
```
**确认**: 去重仅跳过会话创建，事件通过 WebSocket 照常推送岗亭。
