## 优先级定义

| 优先级 | 定义 | 建议排期 |
|--------|------|----------|
| **P0** | 一期已实现但存在安全隐患或功能不可用，必须先修复 | Sprint S2 |
| **P1** | 核心业务流程缺失，对接主要利益相关方 | Sprint S2 |

## P0 — 必须修复（安全/可用性缺口）

### P0-1：小程序 `miniapp:view` 权限未对 wx_user 生效

| 属性 | 内容 |
|------|------|
| **类型** | Bug/安全缺口 |
| **来源** | 一期测试发现 |
| **描述** | wx_user JWT 不携带 `permissions` 字段，`@RequirePermission("miniapp:view")` 对小程序用户返回 403。当前只能通过 admin 账号（如 super_admin）调用小程序接口。 |
| **影响范围** | 所有小程序 API（支付、代缴、余位查询、消息通知、车辆管理） |
| **建议方案** | 在 `WxUserService.login()` 生成 JWT 时，为 wx_user 赋予基本权限 `["miniapp:view"]`；或修改 `SysPermissionProvider` 支持 wx_user 权限查询；或在 `PermissionAspect` 中对 userType=wx_user 用户放行 `miniapp:view` |
| **预估工作量** | 1-2 人天 |
| **依赖** | 无 |

### P0-2：Device Access 开闸真机联调

| 属性 | 内容 |
|------|------|
| **类型** | 联调阻塞 |
| **来源** | 一期 v0.2 契约 `POST /api/v1/devices/{sn}/gate/open` 标记为 NOT_IMPLEMENTED_IN_V0.2 |
| **描述** | 平台 `DeviceService.openGate()` 调用 Device Access 开闸，需真机环境验证 |
| **影响范围** | 远程开闸、识别后自动开闸、手动开闸 |
| **建议方案** | 部署 Device Access v0.4（含开闸端点），更新 base-url 配置 |
| **依赖** | Device Access 团队发布开闸端点 |

### P0-3：微信订阅消息真实接入

| 属性 | 内容 |
|------|------|
| **类型** | Mock 替换 |
| **来源** | 一期 E3 实现 |
| **描述** | `MiniMessageServiceImpl.sendSubscribeMessage()` 当前仅记录日志。需替换为真实 `POST https://api.weixin.qq.com/cgi-bin/message/subscribe/send` |
| **影响范围** | 支付成功通知、后续的代缴通知、月卡到期提醒 |
| **依赖** | 微信 AppId、AppSecret、模板 ID |

## 技术债务清理（穿插在各 Sprint 中）

| 编号 | 项目 | 当前状态 | 建议动作 | 优先级 |
|------|------|---------|---------|--------|
| TD-1 | Snowflake 主键 → AUTO_INCREMENT | 全表使用 Snowflake，19 位 ID 对前端不友好 | 评估迁移方案 | P3 |
| TD-2 | L1 Caffeine 缓存去留 | 已启用但配置变更频率极低 | 监控命中率，低于 80% 则移除 | P2 |
| TD-3 | RabbitMQ 去留决策 | 已建立但无真实流量 | 联调后按 QPS 决策 | P2 |
| TD-4 | Service Worker 离线缓存 | 预配置但岗亭通常有线网络 | 降级为乐观 UI + 重试 | P3 |
| TD-5 | 余位计算真实化 | `ParkingSpacePolicyService.calculateRemain()` 使用硬编码 `usedSpaces=0` | 接入真实 parking_session 计数 | P1 |
| TD-6 | Nearby 查询性能优化 | 纯内存 Haversine 扫描，车场 > 1000 时性能差 | 引入空间索引（MySQL 8.0 ST_Distance_Sphere） | P2 |
