# 停车平台 P0 检查单

## 数据范围

- 所有入口从服务端上下文取得 tenant/parking-lot scope。
- 详情、导出、统计、批处理、异步任务和推送均失败关闭。
- 普通管理员不能跨租户；超级管理员代操作有真实人、目标范围、原因和结果审计。

## 停车业务

- 入场、计费、订单、支付、出场、放行使用同一可信业务上下文。
- 停车记录只通过集中状态机合法迁移。
- 重复入场/出场、并发请求和重复消息幂等收敛。
- 计费规则、月卡范围和有效期来自已确认配置。

## 金额与支付

- Java 使用 BigDecimal，数据库使用 DECIMAL，无 float/double。
- 回调验签并校验 appid、mchid、outTradeNo、金额。
- 重复回调、退款和状态更新具备幂等与条件更新。
- 免费订单是合法零金额路径；负金额直接拒绝。
- 支付与开闸解耦，并有补偿、人工兜底和审计。

## 开闸

- 校验权限、租户、停车场、车道、方向、设备、停车记录和支付/免费/人工条件。
- 从可信平台设备记录读取 device_sn。
- 调用前后均落审计；网络/超时进入 UNCERTAIN。
- 没有任何自动重试、透明重放或重复资金动作。

## 联调与测试

- 不扩大白名单、不关闭鉴权、不硬编码超级权限。
- 不删除、禁用、跳过或弱化测试来伪造通过。
- 跨租户、跨停车场、重复事件、并发、超时和补偿均有证据。
